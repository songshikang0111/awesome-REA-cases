# OpenMontage：参考片节奏到Transformer科普前10秒的具体设想

2026年11月7日14:57:38（北京时间）的候选介绍OpenMontage：给Codex或Claude Code一条喜欢的短视频，研究其开场、切镜与旁白画面配合，再按新选题给两三种拍法，正式制作前先看样片和预估费用。这是参考视频制作结构的研究与生成工作流，不是软件反编译。

发帖者提出具体未执行实验：保留参考片剪辑节奏，换成Transformer如何猜下一个字，先让观众猜句尾，再用动画解释模型，先看前10秒。其意图是用短预览具体纠正提问时机和旁白可听清度，而不是只说节奏更快。没有提供这一实验的输出。

候选转述仓库例子为60秒香蕉与猕猴桃动画，六段Kling镜头、作者标价1.33美元；另有五种硬表面产品的60秒拆解再组装短片，以首尾帧保持产品身份并配音效、旁白与音乐。后者是视觉生成例子，不当作实物工程结构已逆向。77K+星是转述快照。仓库地址称在评论中，但未取得原仓库、生成配置、成本明细或样片对照；费用和质量不是本合集验证。REA只是类比，未证明调用REA。

11月9日20:34:31的新介绍补充12条生产管线、100多个工具、700多个Agent Skills与知识文件，称研究、脚本、分镜、素材、合成和质检在创意检查点等待人决策。参考片可来自YouTube、TikTok或本地文件，输出两三种重构方案和费用估计；还列Piper本地配音、NASA／Wikimedia素材、Remotion／HyperFrames／FFmpeg合成。作者明确只看15秒官方预告Signal From Tomorrow，没有本地跑通；7.9万星是转述快照。Python3.10+、FFmpeg、Node.js和Agent熟练度为其准备要求，不是本合集安装验证。所谓零付费API不等于零计算、素材授权或全部生成成本；SaaS演示、播客切片和多语言频道均为提出的商业方向，不是已实现收入。未运行项目或生成视频。
