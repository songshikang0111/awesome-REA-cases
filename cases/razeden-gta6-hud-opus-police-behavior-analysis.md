# GTA VI警察行为：RazeDen称用Opus逐读50帧HUD推断追捕规则

2026年11月19日19:17:45（北京时间），RazeDen（@razeden0）声称分析GTA VI的警察AI：Mac上用PS5 Remote Play，ffmpeg每2秒取一帧，将100秒追逐的50帧HUD交给Claude Code里的Opus 5.5，要求逐帧读取通缉星、迷你地图警察点和现金，形成行为规格。作者说设置花15分钟、研究一晚；这是屏幕行为研究，不是取得Rockstar源码或反编译警察代码。目标与既有整游戏移植／机制重建愿望不同，独立记录这一具体观测实验。

作者报告0秒有2个警察点、64秒31个，通缉星从1到5；脱离视线后星闪12秒，躲满降一星，11秒被发现会重置；三星时每6个新点有4个出现在车前。还称五星被捕损失21500美元中的8600，一星死亡损失1500；74秒地图显示0警察但画面有巡逻车，是其主动列出的不一致。上述只是作者对所述片段的读数与推断，点数不必等于全场警察数，单段相关性不能证明生成、遮挡或计时规则普遍成立。

计费自述为50帧每帧约1600 token、图像80000输入，另有30000提示输入、25000输出，总花0.94美元、每帧约0.019美元；没有核验模型价格、token记录或账单。开头拿Rockstar约20亿美元、8年与一次观察费用比较，是不同范围，不作为逆向提效比，也不核实游戏发布日期或预算。原帖文字与署名已补读，未审参考视频、原始帧、完整规格、会话、重复实验或实际游戏版本，不能确认所示就是GTA VI。作者也承认模型只能读玩法，不能制作整游戏。按未独立复现的analysis-test保留，不下载游戏、不运行目标；未提REA。
