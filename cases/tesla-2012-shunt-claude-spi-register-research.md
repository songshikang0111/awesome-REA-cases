# 2012 Model S分流器：Christopher读到电流，计划让Claude整理SPI寄存器

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-11-21
阶段：进行中

2026年11月21日04:30:22（北京时间），Christopher Kalitin（@CKalitin）称终于从2012 Tesla Model S的分流电阻装置读出电流。分流器用于通过压降测电流；这里研究的是其读数与SPI寄存器接口，不是整车自动驾驶或高压系统改装。作者称每bit约50mA，并对比自己去年设计的分流器每bit800µA，不过后者电流量程较低：420A对1500A。这不是相同量程或相同实验条件下的精度优劣结论。

下一步是探索剩余SPI寄存器并让Claude写文档，特别是校准寄存器。原帖没有明确Claude参与此前电流读出的哪一步，不能把下一步计划写成AI已完成所有寄存器恢复。补取确认作者、视频和图片存在，未观看或核验硬件、协议捕获、寄存器表、校准和精度；没有操作设备或运行固件。作为进行中接口研究收录，REA未提及。作者同帖另提STM32工具替代idea，单独记录。

11月21日封存快照：7赞、327浏览、0转发、2回复；50mA／bit、800µA／bit与两种量程均为作者报告。
