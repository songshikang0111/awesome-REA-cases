# 停服记账App数据救援：cabbit称REA／Claude导出11年交易，修正时区日期

分类：应用与客户端 · REA
记录日期：2026-11-02
阶段：待验证

2026年11月2日03:45:25（北京时间），cabbit（@cabbitar）称一款未具名记账App于2023年关闭同步服务器，仍能本地打开，但无导出、API，支持页404，11年历史在640MB文件中。作者称给Claude Code文件副本，要求不改原件，读者Agent以REA定位交易加载函数，恢复SQLite中按自有App密码派生密钥的加密金额blob，形成24字段、逐项追到写入代码的规格。

作者报告首轮500笔有37笔日期错误，归因为本地时间与2019年迁居，改一行修复；全量导出18406笔CSV交易、1212张收据照片，保留分类与备注，检查者在原App随机对300笔无差异。拆分交易与扫描PDF仍留原始形式、标手查，原文件自称改动0字节。

补查原帖确认署名与全文，仍未给App名／版本、源码、数据库格式细节、密钥机制、工具输出或抽查日志；所有步骤时间均是[00:00]占位，不能作实际耗时或先后计时证据。保留为具体数据迁出自述，不是完整恢复、密码破解或已审计的只读保证；300笔抽查不能证明其余全部正确。未读取私人财务数据、执行导出或访问凭据。

候选快照8赞、75浏览、0转发；11年、640MB、24字段、18406笔与300笔零差异均为自述。
未具名App；[00:00]是占位而非真实计时，拆分交易与PDF仍待人工检查。
