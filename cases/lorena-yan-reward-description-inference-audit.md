# 奖励描述反推：Tianyi Lorena Yan用高低奖励轨迹揭示模型实际偏好

2026年11月3日06:40（北京时间），Tianyi Lorena Yan（@LorenaYannnnn）回复Max Mao：直接让AI审计grader／奖励模型（RM）是强基线，但同题不同奖励的rollout包含对照信号，可帮助反推实际偏好和潜在利用点，尤其RM是复杂规则或难解释神经网络时。目标不是恢复软件源码，而是用语言模型从训练记录推断黑盒奖励行为，使思维链（CoT）监控更有信息。

补读10月20日23:00北京时间研究串与10月23日10:29提问，均早于本窗口，作为方法背景。作者与John Hewitt的研究构造长度超限、评判模型家族偏好、代码仅过部分测试三类奖励错配。方法从训练中取奖励差异大的轨迹，提示LM生成候选奖励描述，保留能帮助冻结基座获得高奖励的描述，再注入训练输入使模型在CoT表达出来。研究串自报各模型／任务的监控分数改善，却没有在已读文字中给出具体数值。
