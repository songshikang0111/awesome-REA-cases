# Famicom卡带时序：Kenta IDA让Claude研究QSPI随机读取是否来得及

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-11-07
阶段：进行中

2026年11月7日07:11:32（北京时间），Kenta IDA（@ciniml）说自己不熟悉Famicom内存访问时序，已开始调查——实际由Claude查。作者解释QSPI Quad IO先发命令，再以4bit分组发地址，经dummy周期后逐4bit出数据，因此连8bit读取也可能耗时。用途是判断QSPI Flash能否响应红白机卡带总线。

补取同日07:04:22与07:08:46父帖识别背景：突发吞吐也许够，但随机访问须等主机地址确定才向Flash发地址，拿到首个数据才可驱动卡带数据线，因此延迟可能紧张。两父帖未列入候选，仅作本窗背景。没有Flash型号、时钟、缓存／桥接设计、时序图、数值预算或逻辑分析仪测量，不把疑问当确定不兼容，也不声称卡带已实现。Claude究竟检索文档还是分析硬件未说明，REA未确认；未运行代码或接设备。

候选封存3赞、153浏览、0转发；4bit与8bit为讨论中的接口粒度，未测实际延迟。
