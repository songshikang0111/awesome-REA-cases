# Bloomberg 风格研究终端：用 REA 与 Claude 构建独立数据工作站

分类：应用与客户端 · REA
记录日期：2026-11-08
阶段：待验证

发帖者第一人称报告使用 REA MCP 与 Claude Opus 5.5 构建 Bloomberg 风格的金融研究工作站。帖子列出的流程包括观察公开可见的金融仪表板、图表与工作流，设计报价、观察列表、财务报表、新闻、图表和组合分析等功能，接入免费市场数据 API，并制作回测与分析功能。作者明确说没有解锁 Bloomberg 专有数据，而是使用独立数据来源。现有证据是作者的完成自述及其构建指南，没有提供工作站代码、可访问成品或测试记录；故保留为待验证报告，不据此断言已完成全部列举功能或与 Bloomberg 等价。REA 使用是帖子直接自述，本合集未独立复测。

10月16日另一宣传帖声称18岁用户用REA与Opus在一晚重建年费32,000美元终端的告警子集：输入股票与币种、连接Telegram，每个工作日8:00查持仓异动与原因，附来源和时间发送，称一个问题约读23个来源。这一新用途证据按同目标补充，并非确认与原作者同一个实现。宣传帖虽说追踪真实App、写规格、零复制，却又从未具名市场App选模型开始，缺原作者、源码、网络证据与测试；无法确认逆向与普通AI市场助手的分界。年龄、年费、工时、来源数均仅为该帖主张，不证明取得专有数据或交易优势。

10月17日06:26，@sopersone 称一个周末从外部研究功能代码串联、Launchpad面板通信、股票到基本面与期权链切换，再用REA与Opus规格接自有报价、新闻、经济日历、收益率曲线、财务与期权数据；还称加入跨资产筛选语言与含费用、滑点、回撤的回测并逐功能对照。约30,000美元年费、工时与测试均为该作者说法，未确认与前帖同一实现，未取得代码或对照记录，不确认Bloomberg等价。

10月22日07:12（北京时间）的候选另提出REA、Claude Code与Kronos组合：先映射专业终端的报价、图表、筛选与新闻界面，再接公共市场API，加载其所称24.7M参数的Kronos-small，以512根历史K线预测后24根，采样100条价格路径显示分布，并要求在使用真金白银前计入真实费用回测。这是增加概率预测层的具体idea，不是确认与旧帖相同实现。帖子没有终端代码、模型评估或回测结果；模型大小和输入输出设置只归于该帖，未核查Kronos仓库或执行预测。免费、Bloomberg式界面与预测曲线均不意味着得到专有数据、收益保证或完整终端等价。

2026年10月24日01:48:40（北京时间），另一提案在这一终端目标上加入TradingAgents：四个AI分析者分别看基本面、新闻、情绪与技术面，再经多空辩论、风险团队和组合经理评估BUY/SELL/HOLD。REA负责研究专业终端界面与流程，Kronos继续提供概率预测，TradingAgents增加研究与决策组织层。帖子重复24.7M参数、512根输入、24根预测和100条路径的设置，并要求计入实际交易成本回测后再使用资金。仍无终端实现、回测、预测质量或收益记录，也未核验模型、Agent数量与免费运行条件；不确认与前帖同一代码。

2026年11月2日23:46:45（北京时间），另一候选评论REA／Kronos／Claude Code研究台，强调数据源、限频、延迟和时区对齐比拼界面更难。它泛举免费股票数据可能延迟15分钟、Level-2数据月费数百至数千美元，以及所见某拼装方案模拟盘信号慢几十秒、滑点吞掉收益的故事；没有指明供应商、项目或账本，这些不是已核实价格或本终端实测。作者计划用同一栈跑一周，记录数据源失败率、端到端延迟、信号与人工判断差异，再对照公会游戏次日／7日留存与真实付费。该跨研究台与链游的计划尚无结果，不能把“能跑”的评论升级成已完成评测，亦未确认与旧作者同一实现。

2026年11月4日05:55:42（北京时间），新帖提出Day Trader Skill与REA组合：研究有权访问的金融界面布局和行为，用Claude Code搭建Bloomberg风格图表、筛选、成交量分布和研究面板，再串扫描、新闻、入场／退出、预算、风险与经明确批准的模拟盘。帖称11项技能，其中timemachine按历史K线模拟10000种结果，另提3D市场可视化。它是不同于Kronos／TradingAgents的具体方案，不确认与旧作者同一实现。没有终端代码、已分析目标、回测、模拟盘账本或收益记录，技能数量和模拟质量未核查；模拟不代表预测准确或实盘收益，免费仓库也不代表市场数据及运行完全免费。未安装技能、访问券商或交易。

2026年11月8日04:45:58（北京时间），新候选称用REA与Opus 5.5把TradingView图表和Bloomberg命令合成自用终端，列出蜡烛图、周期、画线、指标、提醒及GP／FA／WEI／TOP／<GO>，提出接免费公开行情、Telegram提醒与保存布局，并让读者用NVDA US Equity GP <GO>试验。作者称年省32400美元、零月费，但未给仓库、账单、数据源授权、延迟说明或对照输出，结尾索要repo链接不是已有代码。指南中的自动找到数据不是已核实的数据覆盖；不代表取得Bloomberg专有数据、付费TradingView功能或完成全部服务。本帖同时补到两项既有目标，不确认与早期作者是同一实现，本合集未运行。
