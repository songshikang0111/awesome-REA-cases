# ARTEX活体检测协议逆向：MadPot二手调查称接近目标仍全部被服务端拒绝

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-11-14
阶段：待验证

2026年11月14日10:03:48（北京时间），一则长帖转述Amazon MadPot诱捕系统在10月3日至11月5日接收的ARTEX Agent请求。传感器伪装成模型推理接口，Agent把历史上下文、任务与工具记录送入请求。帖子明确Amazon没有实时目睹原活动，无法验证Agent自报的结果；ARTEX归属及中国关联均只是中等置信度调查判断，不能据中文提示、时区或工具界面确定操作者身份。

本条只记录其中针对两家未具名加密货币交易所KYC（身份核验）的具体逆向尝试：Agent研究一家供应商的活体协议，包括人脸检测事件流、追踪与坐标系统。按该帖，最佳记录进入目标位置7像素以内，但每次有记录的深伪尝试都被供应商服务端拒绝。另一会话在单消费级GPU上建立实时深伪管线，报告11.5帧每秒；吞吐量不是通过活体核验。帖子也提到伪造身份照片的文件属性处理及至少四个并行会话，只作为活动背景，不提供复现或绕过步骤。

完整长文还讨论凭据窃取活动，但本条不扩展为利用教程，不声称任何账户被成功接管。未取得Amazon原报告、原始任务记录、供应商名称、样本、源码或独立测量，7像素与11.5帧每秒均保留为二手数字。模型及REA使用未明确，不与既有ARTEX Android研究、Profero应急项目强行认定同一操作者或事件。本合集没有访问凭据、下载框架、运行深伪或尝试KYC绕过；按未核验调查转述保留失败与证据限制。

候选快照7赞、464浏览、1转发、4回复；7像素和11.5帧每秒均不是攻击成功率。
