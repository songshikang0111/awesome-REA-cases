# 竞争Agent群重写实验：跨队反编译、隐藏故障与独立裁判的idea

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-10-31
阶段：待验证

2026年10月31日03:51:16（北京时间），@EERandomness提出一个竞争式多Agent重写实验：多支相互不能直接通信的swarm团队，由Grok、Claude、GPT-6、DeepSeek、GLM等前沿及上一代模型混合构成，用多种自然语言及代码式目标提示，分别独立重写整个代码库。没有指定代码库或既有软件，这是一套具体研究方法idea，不是已完成的迁移项目。

每队红队读取本队代码并攻击其他队的编译二进制，将所谓CVE放入共享数据库；允许反编译对手二进制，把发现用于本队改进。独立裁判持续评估功能等价、性能与规格符合度，并维护公开排行榜。每队另设一个故意引入bug的“双面Agent”，只向裁判私有数据库记录，以帮助构造测试与红队指标；故障注入不是发现真实供应商漏洞，文中的CVE称呼也不表示已获正式编号。

作者还设想裁判分阶段追加功能以影响架构，并让团队依据指标互改提示，双面Agent提示由对手编写；最后按指标选最佳结果、弃其余。补查完整原帖确认这些方案细节，未见执行、成本、样本、测试集、代码或排名。不能把“更多算力更好”观点当实验结果，也不假定所列模型实际可用。REA未提及，本合集没有启动Agent群、反编译目标或执行研究代码。
