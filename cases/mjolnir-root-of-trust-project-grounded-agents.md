# Mjolnir：让Agent按项目威胁模型研究信任根固件与RTL漏洞

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-11-23
阶段：分析测试

2026年11月23日12:19:22（北京时间），@gastronomy发布Mjolnir研究摘要，目标是Caliptra、OpenTitan和OpenPRoT中的六个信任根固件与RTL目标。信任根支撑安全启动和证明；相关缺陷可能取决于项目特有信任边界、故障注入防护，且不一定崩溃，因此不能只找通用漏洞模式。这里按AI辅助理解硬件/固件安全行为的分析研究收录，不称从二进制恢复原始源码。

摘要描述把项目威胁模型和设计惯例交给发现Agent与持怀疑态度的复核Agent，再为保留下来的发现编写原项目工具链中的PoC测试。没有实物信任根时，依赖硬件模型、mock或RTL testbench来驱动输入；这种项目内复现不能等同真机故障注入验证。

据摘要，在Caliptra运行时固件上，三模型经盲法专家标注的precision为83.3%至100%；Gemini 3.8 Flash为100%，同模型四个单Agent基线为66.7%至78.6%。对模型训练截止后修复的34个已知核心固件安全问题，Gemini 3.8 Flash找到10个，最佳基线7个；Gemini 4 Argon找到17个，最佳基线12个。这些是特定评估的精确率和找回数，不是所有目标的准确率或全部漏洞召回。

摘要另称维护者确认64个此前未知的安全相关问题：Caliptra运行时固件三模型扫描合计37个，其余五目标的单次扫描合计27个。未取得原论文、模型配置、逐项发现、去重口径、维护者确认记录或PoC测试日志，故确认数量仍明确归因摘要，不升级成独立审计结论。补取原帖串核对署名与文字；短链未展开。REA未提，本合集未执行任何固件、RTL、目标代码或测试。
