# iOS相册到Immich客户端：转述REA列226操作、147实现与8.5万媒体自测

分类：应用与客户端 · REA
记录日期：2026-11-11
阶段：进行中

2026年11月11日19:30:07（北京时间），uudon（@uudonX）转述一位不熟iOS开发的用户，为避开iCloud订阅、保持照片在自有服务器，把8.5万照片与视频迁至Immich，却不满意第三方客户端体验，于是用Claude重做熟悉的相册。它不同于既有Homecloud私有请求迁移案例，目标是以苹果相册行为为参考的新Immich客户端。

报道称Claude Code接REA研究iOS26.3相册框架，列出226操作，如复制编辑效果、隐藏、设封面、拖入相册和Spotlight搜索；一个Agent只写操作会发生什么的行为描述，再据此实现，意在不复制苹果代码。Claude写代码与UI测试，在模拟器运行并截图比较，用户决定范围、每天真机试用并反馈；8.5万媒体造成早期崩溃卡顿，经多轮真机调优改善。按报道目前147操作可用，剩余多依赖iCloud。

原件在自有服务器，手机缓存时间线与缩略图，离线浏览、新照自动备份、确认备份后才能删除及仅连自己服务器，均为转述的设计或功能主张，未审网络或数据删除安全性。226是枚举分母，147不是独立测试通过数，不能把遗漏都当无法实现。补取确认转述者与正文；未确认原开发者、仓库、许可、规格、测试覆盖、设备、性能或8.5万媒体迁移记录，不把开源与净室说法升格为法律合规判断。文末关于绕过模型拒绝的对话未提供研究方法或可核成果，不作为技巧传播。本合集未读取私人照片、接入服务器或构建客户端。
