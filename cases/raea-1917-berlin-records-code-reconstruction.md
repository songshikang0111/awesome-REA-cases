# 用raea重建1917年柏林：Claude读地址簿，地图与照片变成可编码场景

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-11-22
阶段：相关项目

2026年11月22日05:04:53（北京时间），Shane（@shinyobjectz_）介绍以raea重建1917年柏林的项目。起点是Ritterstraße马厩楼上一间小房的住房调查照片，照片下有尺寸；团队想站进这间房，于是按旧记录把周围城市也重建出来。作者称用1910年地图生成建筑平面、按1887年楼高竖起建筑，按照片说明写房间尺寸，让Claude读取1917年地址簿以放入屋主、商店和租户，再描摹1884年下水道图集生成地下网络。

作者称纪录片长9分半，镜头、标注和剪辑全用代码，部分渲染用AI视频收尾并在画面标记AI镜头，且代码开源可重渲染。补取确认署名和视频附件，未观看影片、取得源码或逐项对历史档案。不同年份材料不能直接证明每栋建筑在1917年同时如此；Claude读地址簿也不证明每个姓名匹配正确。raea不等于REA，没有二进制分析证据；作为AI辅助历史场景复建相关项目收录，不认证城市级精度或一键复现。
