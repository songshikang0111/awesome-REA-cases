# 400函数应用的Grok／Fable分流：旧约5美元与后续3.10美元报告分开看

分类：应用与客户端 · REA
记录日期：2026-11-17
阶段：分析测试

2026年11月13日19:40:11（北京时间），@starmexxx发布Fable5.2、Grok4.6与REA的五种配置文章。可读正文称当周映射五款付费应用总账单14美元，但只有一款未具名的400函数菜单栏应用有具体过程数字，故保留为一个低细节分析实验，不捏造另外四个目标。作者称Grok单独跑41分钟、1.80美元，基础结构较准确、两个数学函数不稳；混合方案先让Grok标注，再将不确定部分交Fable，400个中37个升级、其余363个为基础结构。

旧文章把混合路线称为约5美元且达到Fable级结果、约三分之一价格。这些是作者估计与评价，没有逐函数答案、匹配定义、准确率、模型调用账单或同条件基线。五款14美元不等于本次混合费用，八worker与完整实验室只是配置建议。其他游戏、模型价格、REA能力与Craft Anything的概述不作为此实验已验证事实。

11月17日01:56:18，Ridark（@ridark_eth）自述在Grok与Fable之间加置信度0.8门控：REA给各函数伪代码，Grok返回一句用途、置信度与疑点的JSON，高于0.8保留，低于则交Fable 5.2研究输入、输出和副作用，标observation／inference／unknown。400个中363个留在便宜路线、37个升级。来源未说明恰好等于0.8怎么处理。Ridark列Grok单跑41分钟／1.80美元／19个unknown，Fable单跑26分钟／9.40美元／4个unknown，混合33分钟／3.10美元／5个unknown，并称账单降67%。这与旧文约5美元不同；没有条件与账单，不能把它直接改写成旧实验更正、受控重复或准确率提升，unknown更少也不证明判断正确。

02:17:25，Mojunel.eth（@mojunel）又报告400函数、41分钟1.80美元与五应用一周14美元，说明CLI注册Agent、doctor查引擎、native用Ghidra而Electron读脚本，追click／handler／IPC／network路径、按调用次数取top30带证据ID写研究Markdown，按build版本化。每六秒一个函数、每call不到半美分及每次有证据都是该帖自述；函数和调用不是同一计费单位。

补取确认两位后续账号与原句，其数字高度相似但没有应用身份、版本、报告、脚本、捕获日志或逐函数答案，无法证明它们是独立实验、同一运行或同一作者。按原目标补证而非重复开案，并保留分别归因。未审附件视频、执行REA、配置模型或复核账单；保留analysis-test。
