# Yapfast：Hemish称Rust版Discord替代客户端已有通话

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-11-08
阶段：待验证

2026年11月8日05:41:47（北京时间），Hemish（@imhemish）回复关于mod的讨论，认为AI会让mod继续存在，并称已经逆向出Rust编写的Discord客户端，带可工作的通话。补取展开链接为Yapfast官网；链接卡片将其介绍为Windows／Linux原生Rust Discord客户端，称支持语音、视频与共享屏幕。

具体目标是替代重量级官方聊天客户端，而不是给官方计划中的Rust版做mod。AI关联来自作者所处讨论和表述，未给模型、提示或具体逆向阶段，不能升级为已核验AI开发记录。卡片约30MB对720MB内存是宣传对比，未核配置或测试，不作测量值。未读源码、访问账户或测试通话，也不确认所有功能、协议兼容或服务许可；REA未被提及。与基线Discord新客户端mod idea分开记录。

封存1赞、68浏览、0转发；链接目的与卡片经补查，未测试产品。
