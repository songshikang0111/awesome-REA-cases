# Android隐私重建工作流：从REA与代理对照idea到眼镜语音助手自述

分类：应用与客户端 · REA
记录日期：2026-11-25
阶段：待验证

2026年11月24日23:22:12（北京时间），Sad HAM Society（@Sad_HAMs_）给出Android应用隐私研究的工作流idea：让Claude Code连接开启调试的手机，取得感兴趣的App，用REA反编译并列出发送的数据与目的地，再代理实际通信、对照同一问题。其用途是把静态代码中可能发送的数据与运行时观察分开，不是已经完成某个App的隐私审计。作者还建议重编译、改名并删除不希望的数据采集，再安装回手机。

11月25日06:50:01，作者另帖声称自己购物时可通过带HUD的智能眼镜语音调用自建AI助手：从手机取出App、反编译、静态分析、修改、重编，再经Tailscale推回手机；可用前沿模型或自家实验室的开放权重模型。这比原idea增加实际使用的作者宣称，但没有命名眼镜、手机、App或模型，也没有补丁、部署录像、请求记录或成功安装证据。新帖未再次点名REA，不能把整个助手都说成REA实现，也不能据回传宣称隐私逻辑已完整移除。

同日07:21:10，Rank Badjin（@badjin_rank）在原Android工作流的回复链中引用一段未标明来源的文字，质疑Claude Code常因内置保护拒绝这些步骤、工作流可能受阻或不可靠。这是读者异议，没有具体拒绝文本、运行环境或失败复现；不能裁定作者虚构，也不能保证Claude或所有App均能照做。两条候选的补取确认署名与回复关系。

所有来源仍缺应用版本、源码、抓包、证书环境和安装验证。无法确认全部流量可见、签名与完整性检查可通过或修改安全。本合集没有执行调试、代理、手机取包或重编步骤，保持unverified；既有REA idea、后续使用宣称与读者异议分层保留，不作为普遍可行教程或授权结论。
