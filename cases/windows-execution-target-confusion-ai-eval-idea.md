# 点击A却执行B：以20个Windows漏洞设计AI行为判断与修复回归评测

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-11-18
阶段：相关项目

2026年11月18日17:29:49（北京时间），一则团队帖子介绍10月21日在数据组流传的公开说明，主张把模型的安全判断作为单独训练和评测能力：预测危险行为、判断输入可信度、发现漏洞及验证修复。帖称团队刚整理20个Windows漏洞，举出‘用户点击A，软件执行B’的执行目标混淆，涉及进程启动接口的回退处理。

具体idea是把操作记录与程序行为证据给模型，检查它能否定位目标改变处、解释触发条件，并验证修复不破坏合法行为。团队还提出按难度、环境和评分器界定二进制、Web安全、逆向及0-day风格任务，而不是出售利用或一堆答案；这是针对行为证据的AI评测设计，不是已经公开全部漏洞或复现攻击。

10月21日是帖子引用说明的日期，不是本轮候选发布日期，也未单独取得该说明。帖子明确不是实时榜单或具名模型当前成绩；未给CVE、样本、环境、评分器、通过的参考实现或修复差异。本合集未审代码、原始漏洞或运行任务；20个为团队整理数量，不是20次AI成功发现，权限、沙箱与审计也不能被模型判断替代。REA未提及，按相关评测idea保留。
