# Colin McRae Rally 2005: statically recompiling the Xbox release for modern Windows

At 16:30:16 Beijing time on November 10, 2026, yibie (@yibie) lists Colin McRae Rally 2005: the Xbox version statically recompiled for Windows, with AI participation recorded in 21 commit trailers. Supplementary reading of the public list identifies projectedan/McRae05-XBE-Recomp, whose README explains the purpose. An old PC release already exists but lacks modern-controller and 64-bit support; this unofficial port uses Xbox XBE Recomp to address those gaps.

Documentation specifies Windows 10 64-bit and Direct3D 12. It describes first-run code compilation, a 60 fps cap because physics steps once per frame, modern-controller hot plugging and rumble, rendering options and an emulated Xbox audio DSP. Only the US NTSC Xbox default.xbe is supported; European releases may crash and PC data is not a substitute. Users must supply legally obtained game files; assets are not distributed by the project. These platform and compatibility claims are not hardware tests here.
