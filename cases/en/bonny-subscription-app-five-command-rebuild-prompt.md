# Rebuild only the features you use: Bonny's five-command subscription-app research workflow

Category: Applications and clients · Other AI-assisted work
Record date: 2026-11-27
Stage: Needs verification

At 06:05:13 Beijing time on November 27, 2026, Bonny (@bonnyxen) introduces an AI prompt workflow intended to reduce reliance on subscriptions. A user supplies a paid app's link, screenshots or screen recording and specifies what to keep. The model would map screens, buttons, flows and edge cases, select what the post calls the commonly used twenty percent, implement it step by step with setup/run commands, then compare against the original and identify gaps. Claude, Gemini and ChatGPT are listed as model choices, not three completed experiments.

The five commands are /scan, /cut, /build, /test and /fix, for analysis, scoping, coding, comparison and repair. The workflow also asks the model to distinguish observations from guesses rather than pretending to have inspected a backend. These are described capabilities, not a published complete prompt or test log. The post promises the full prompt below; this collection did not obtain that text, a named target app, reconstruction repository or comparison results. Thirty dollars a month and four screens plus a database are marketing examples, not measured savings or proof of a target's structure. Retained as a concrete behavior-study/rebuilding idea, not a claim to clone arbitrary apps or bypass subscriptions. REA is unmentioned.
