# Xenosaga Trilogy Port: Claude-assisted PS2 decompilation ports for Linux, with Episode III still unavailable

Category: Games and preservation · Other AI-assisted work
Record date: 2026-11-28
Stage: In progress

At 19:51:11 Beijing time on November 28, 2026, The Gaming Emporium introduces xenosagaport's Xenosaga Trilogy Port, combining the PS2 trilogy into one Linux launcher and AppImage and crediting Claude Code-assisted development.

Supplementary reading covers README 5e3b605eef3cbda937aed0775efa87cc3cf42d4d, committed November 28 at 11:28:36 UTC, before the candidate and inside this window. The author explicitly credits Claude/Claude Code for the ports, launcher and tools, built on OpokXeno's three decompilations, which the document also describes as AI-assisted. Episode I is reportedly playable, II playable but still with issues and in testing, and III coming soon. Windows is only planned. Listed features include true 16:9, Episode I speed and battle-animation skipping, an Event Theatre, optional HD packs and shared memory cards. One unified launcher does not mean all three games are complete.

Players need their own legally obtained NTSC-U disc images; no BIOS is required. Build/release checks reportedly read needed VU microcode from user discs, verify hashes and detect shared runs of 32 or more bytes, with exceptions for source-explicit tables and standard library tables. This is a project process, not independent verification that copyrighted bytes are absent. The README acknowledges upstream decompilations lack license files as of writing; open visibility is not unrestricted relicensing permission. There is no GitHub Actions build because matching PS2 builds require game data. Only documentation was read; no games or releases were downloaded and no tests run. Several weeks of development is the author's estimate, not measured effort.

Candidate snapshot: 1 like, 37 views, 1 repost, 0 replies. Playability is project-reported.
