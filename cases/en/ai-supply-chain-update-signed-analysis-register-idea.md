# Signed analysis for every software update: P Flodin's AI supply-chain public-register idea

Category: Applications and clients · Other AI-assisted work
Record date: 2026-11-18
Stage: Needs verification

At 04:21:05 Beijing time on November 18, 2026, P Flodin (@pflodin) proposes a concrete use for AI companies claiming to hold powerful unreleased models: rather than only producing mathematical proofs, scan, decompile and analyze every new software supply-chain update and publish the results in a public register. The aim is to give software-management systems citable update-analysis evidence when deciding what to install. No particular software target is named.

The proposed report would include the update's hash, an agreed scoring system covering newly introduced or fixed issues, and a signature. Installation systems could use this as a policy input, for example requiring scans by at least two services before allowing an update. This connects analysis reports with installation decisions as an idea; it is not an operating public scanning service or evidence that models can detect every problem.

Original-post retrieval confirmed attribution and the full proposal. There is no public implementation, analyzed sample, scoring specification, signing scheme, model name, false-positive rate or deployment. At least two services is the author's policy example, not a validated security threshold. REA is not mentioned. No updates were downloaded or scanners run here. A signed report is not equated with software safety or independent verification; this remains an unverified idea.
