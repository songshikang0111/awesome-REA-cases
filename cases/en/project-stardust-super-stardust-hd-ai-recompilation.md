# Project Stardust: an AI-assisted PS3-to-PC static-recompilation alpha for Super Stardust HD

Category: Games and preservation · REA use unconfirmed
Record date: 2026-11-25
Stage: In progress

At 15:20:05 Beijing time on November 25, 2026, The Gaming Emporium (@TheEmporium83) introduces thelastant's Project Stardust v0.1.0-alpha.2, a static PC recompilation of Housemarque's 2007 PS3 twin-stick shooter Super Stardust HD. The post explicitly credits AI-assisted research, IDA Pro, MCP tools and Reverse Engineering Assistant. That name alone does not identify morluto/rea, so rea remains unknown and no model is inferred.

The account describes translating original PS3 PowerPC and SPU instructions into native C, with a custom Vulkan runtime for required graphics and system services. A Windows builder reportedly validates game files, downloads dependencies and produces an executable. Other listed features include GameInput controllers and keyboard controls, F1 settings, persistent configuration, shader caching, a dedicated save directory, desktop shortcuts and original-game artwork integration, plus an experimental Apple Silicon macOS build workflow. This is a relayed feature inventory: source and release notes were not read, and it is not a set of tests passed by this collection.

The source explicitly calls development very early: gameplay was achieved during development, but a freeze after approximately three minutes is unresolved, and full-game completion and graphical accuracy are unverified. It requires an owned European NPEA00014 copy at game version 6.00 and PS3 firmware 4.93, and says the current release contains source and build tools only, not the game. No game, firmware, release package or dependencies were obtained, and neither builder nor target code was run. Compatibility and distribution scope remain this post's account, not certification of asset-free distribution or support for every platform. This is an in-progress project retaining its concrete freeze limitation.
