# Nimbus: AI-assisted native Dragon Ball Z GameCube trilogy project, still a closed-source alpha

Category: Games and preservation · Other AI-assisted work
Record date: 2026-11-02
Stage: In progress

At 17:39:14 Beijing time on November 2, 2026, the candidate introduces thebabyhippo303's Nimbus Project: bringing the NTSC-U GameCube games Dragon Ball Z: Budokai (2002), Budokai 2 (2003) and Sagas (2005) into one native Windows/Linux/Android launcher with online play, crossplay and Original/Remastered modes. The candidate still names Alpha 1.0 dated November 1 and explicitly notes closed source and unverified full-game compatibility.

Supplementary public-project reading pins commit e68a5e6cb04e956533189b6d7e43752ac1a43dbf, dated 2026-11-02T09:11:14Z, or 17:11:14 Beijing time, about 28 minutes before the candidate. Its README already lists Alpha 1.1 (November 2) and 1.0 as the previous release. It lists Linux x86_64/Ubuntu 26.04, Windows 11 x64 with AVX2 and Vulkan only, and Android 13+ arm64 builds. This original project document is supporting evidence, not an additional new candidate; no build was downloaded or checked.

The README claims per-game native cores sharing a host and renderer, hybrid recompilation/decompilation without an emulator or hardware interpreter. Detailed architecture remains forthcoming; source is withheld during networking and compatibility work and the repository contains release distributions only. AI disclosure is just 'Made with AI assistance,' without model or roles. Cross-platform networking, complete playthroughs of all three games, rendering equivalence and native architecture remain project claims, not findings independently verified here. Users need their own NTSC-U discs. The project's statement that it includes no original disc images does not audit rights in every runtime component. No release or dependency was executed or installed.
