# Browser patch gaps: Choblin relays Epoch's GLM 5.3 Firefox/Chrome comparison

Category: Applications and clients · Other AI-assisted work
Record date: 2026-10-30
Stage: Needs verification

At 06:13:45 Beijing time on October 30, 2026, Choblin (@choblin29) relays Epoch AI browser testing with open-weight GLM 5.3: over $100,000 spent on Firefox and roughly another $100,000 on Chrome. The same harness reportedly failed to compromise Chrome but compromised all six Firefox releases from September 17 through October 26 in controlled tests. The described method studies the patch gap between public security fixes and their delivery to users, not discovery of every unknown vulnerability.

The writer claims webpages could steal a local file on a visit without clicks, with each new Firefox exploit costing about $1,000 after setup and autonomous development taking as little as 12 hours. They also claim no API refusal from any provider. Numbers, success criteria and autonomy come from this secondary account. A fastest time is not the duration of every attempt, and an absence of refusal establishes neither attack correctness nor authorization. REA is not mentioned.

This review checked original attribution and text but did not obtain Epoch's primary report, release list, logs or code. No exploit was executed, attack page visited or browser tested. Retained as an unverified comparative-research report, not evidence that real Firefox users were compromised or that Chrome is permanently safe after one bounded failure. Both browsers belong to one comparison, not two invented independent projects.
