# Browser patch gaps: secondary reports of Epoch's GLM 5.3 Firefox/Chrome comparison

Category: Applications and clients · Other AI-assisted work
Record date: 2026-10-31
Stage: Needs verification

At 06:13:45 Beijing time on October 30, 2026, Choblin (@choblin29) relays Epoch AI browser testing with open-weight GLM 5.3: over $100,000 spent on Firefox and roughly another $100,000 on Chrome. The same harness reportedly failed to compromise Chrome but compromised all six Firefox releases from September 17 through October 26 in controlled tests. The described method studies the patch gap between public security fixes and their delivery to users, not discovery of every unknown vulnerability.

The writer claims webpages could steal a local file on a visit without clicks, with each new Firefox exploit costing about $1,000 after setup and autonomous development taking as little as 12 hours. They also claim no API refusal from any provider. Numbers, success criteria and autonomy come from this secondary account. A fastest time is not the duration of every attempt, and an absence of refusal establishes neither attack correctness nor authorization. REA is not mentioned.

At 04:40:24 on October 31, 2026, another candidate repeats about $1,000, a fastest 12 hours and $100,000 of unsuccessful Chrome attempts. It adds a claim that the model chained a patch-gap issue with a previously unknown sandbox escape to read local files after a page visit. This is a new secondary chain description, not this collection verifying zero-day discovery. The Firefox release, vulnerability and applicability to all successful attempts are unspecified.

An earlier lookup confirmed the first post's attribution and wording. Epoch's primary report, release list, logs and code remain unobtained this round. No exploit was executed, attack page visited or browser tested. Retained as an unverified comparative-research report, not evidence that real Firefox users were compromised or that Chrome is permanently safe after one bounded failure. Both browsers belong to one comparison, not two invented independent projects.
