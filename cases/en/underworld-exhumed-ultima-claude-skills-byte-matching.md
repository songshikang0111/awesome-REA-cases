# Underworld Exhumed: Exhume's Claude Code skills support rebuilding both Ultima Underworld games

Category: Games and preservation · Other AI-assisted work
Record date: 2026-11-20
Stage: Needs verification

At 00:34:04 Beijing time on November 20, 2026, The Ultima Codex introduces byte-matching decompilation and Windows, macOS, Linux and browser ports of both Ultima Underworld games. Project-name research located abedegno's Underworld Exhumed, preserving DOS behavior from The Stygian Abyss (1992) and Labyrinth of Worlds (1993). The two games in one repository form one preservation project, separate from the Borland compiler case.

The project README at November 17 UTC commit 54ffea7 and a pinned Exhume README were read as supplementary evidence. Exhume explicitly provides Claude Code skills and tools for compilation, per-function matching, link comparison, recorded replay and fuzzing, originating in UW2. This supports AI assistance, not sole AI authorship. The project reports original Borland tools producing whole-file byte-identical UW.EXE and UW2.EXE. Ports from the same source reportedly use seventeen and thirteen DOS recordings respectively to check macOS, Linux, Windows and the web build under Node.js. An older Exhume snapshot has different session counts; these are not independent measurements to add together.

The project lists 89 C files and 50 assembly modules for UW1, and 99 C files plus assembly for UW2, with releases 1.0.3 and 1.2.4 respectively. These are project reports. Complete verification logs were not audited, CI not run and games not built or played here. Byte identity does not establish uniquely recovered original source. Native ports require legally obtained game data; original-tool licensing does not authorize derived game code or assets. The separately hosted browser game was not opened. Supplementary documents predate the candidate window; REA is unconfirmed. Status remains unverified.
