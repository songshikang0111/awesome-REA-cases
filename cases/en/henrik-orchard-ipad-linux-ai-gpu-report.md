# Orchard iPad Linux: Henrik confirms Codex/Opus low-level GPU work without REA

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-10-31
Stage: In progress

At 17:09:33 Beijing time on October 31, 2026, Henrik Klee (@henrikklee) answers a model question in Tom Ballard's old-iPad Linux thread: he started with Codex in Pi and now mostly uses Claude Opus. He explicitly did not use REA; Opus calls tools itself. He says low-level GPU work initially drew some refusals before work continued, without explaining how refusals were handled or naming the tools. The context is his Orchard/Omarchy Linux adaptation for old iPads, not an AI rewrite of iOS. Tom's root-post report of 60fps video on an iPad mini 4 is not attributed to Henrik.
