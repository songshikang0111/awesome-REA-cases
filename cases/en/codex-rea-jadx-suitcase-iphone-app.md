# After the suitcase app disappears: Diego uses Codex, REA and JADX to recover weighing and Bluetooth locks

Category: Hardware and interoperability · REA
Record date: 2026-11-06
Stage: In progress

At 06:00:52 Beijing time on November 6, 2026, Diego (@diego_smez) says packing for a trip prompted a wish to use a suitcase's built-in scale and Bluetooth lock. The original app had disappeared from the App Store, leaving these functions unusable for ages. An old Android APK was found, Codex studied it using REA and JADX, and Bluetooth commands were tested against the author's actual suitcase. Diego describes lifting the case, checking whether the lock opened and pasting logs into chat: physical feedback for the investigation, not just agent guesses about an interface.

The author reports a native SwiftUI iPhone app in about an hour, listing auto-connect, weighing, lock/unlock and widgets. Retrieval confirms authorship and two attached images, but no suitcase brand/model, APK version/hash, command specification, source repository, installable release, weight calibration, reconnection or lock-state test logs were obtained. Feature coverage and reliability cannot yet be checked. About an hour is the author's time estimate, not independent timing or total cost, and does not imply support for all Bluetooth luggage.

This is a device-interoperability project responding to a vanished client. Hardware testing is author-reported, not reproduced by this collection. No APK was downloaded, target run, Bluetooth device connected or physical lock operated here. No public license or reproducible implementation was obtained, so an open-source app release is not claimed.
