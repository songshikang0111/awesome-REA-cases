# Thumbwise: reverse-engineered iOS Home Screen storage meets Claude/Codex layout control through MCP

Category: Applications and clients · Other AI-assisted work
Record date: 2026-11-28
Stage: Related project

At 06:18:04 Beijing time on November 28, 2026, Drake (@Copypaster3000) pitches Thumbwise as a Mac alternative to Apple Configurator. He says the lack of a public Apple API led to weeks of investigating iOS Home Screen storage. Apply reportedly writes and verifies the exact designed layout, including gaps, configured widgets and multi-page folders, while MCP gives agents access to usage data. Duration, the absence of an interface and exact writes are author claims, not individually verified; they do not establish AI performed the underlying reverse engineering.

Supplementary reading of the public site on November 28 confirms the product name and AI-interoperability path: with user authorization, Claude or Codex can use layout and available app-usage data through MCP to arrange icons. Users preview the result and select Apply to write it to an iPhone. The site says it backs up before each Apply and can restore earlier layouts. Requirements are an Apple silicon Mac with macOS 15 or later, an iPhone on iOS 27 and a USB data cable; iPad and iPhone Duo are unsupported. Although the site says layouts and activity stay on the Mac, data handling after connecting an external AI was not audited here; marketing does not establish a privacy guarantee.

Included as a related project connecting reverse-engineered capabilities to AI control, not independently reproduced protocol recovery. Layout protocols, source, read/write logs and before/after widget comparisons were not obtained. No demo was watched, client downloaded or phone connected. MCP and restore functions remain project-described capabilities; REA is unmentioned.
