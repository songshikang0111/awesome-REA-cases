# An abandoned notes app: an author reports REA/Claude exporting 14,212 notes and fixing shared images

Category: Applications and clients · REA
Record date: 2026-10-30
Stage: Needs verification

At 02:13:26 Beijing time on October 30, 2026, a candidate says an unnamed notes app abandoned in 2022 holds nine years of writing since 2017, with no export or documentation and only a 2.3GB proprietary file. Fearing an OS update would make it unreadable, the author says a copy was given to Claude Code at 23:04 with the original protected. REA traced the note-saving function. By 00:52 the reported format was linked compressed 4KB blocks with a separate image pool referenced by IDs; by 02:14 a 31-field specification was traced to writing code.

The post says an initial 200-note export at 03:21 lacked images in six notes. At 04:06 it identified two notes sharing one image while the exporter copied it only once, reportedly fixed in one line. A full run at 05:49 yielded 14,212 Markdown notes and 4,517 attachments with original dates. At 05:58 checkers reportedly compared 200 random notes with the old app and found zero mismatches. Handwriting and audio stayed raw and marked for manual checking; zero bytes of the original reportedly changed. All times, counts and fixes are the author's narrative. The overnight date relationship has no independent logs and is not a controlled timing test.

No app name, exporter, data sample, field specification or sampling report is supplied. Zero sample mismatches does not establish full-data correctness or transcription of handwriting/audio. Separating builder and checker agents is the author's method, not independent reproduction by this collection. No private notes were read or exporter run here. Status remains unverified; the app is not guessed to be Apple Notes or another named product.
