# Rebuilding a rainy city silhouette: DagongAI tries image-to-Muse prompts and reports three defects

Category: Algorithms and feature recovery · Other AI-assisted work
Record date: 2026-11-20
Stage: Needs verification

At 13:10:54 Beijing time on November 20, 2026, 打工战士 (@DagongAI) reports trying a small open-source tool called Prompt Reverse Engineering: a reference image is analyzed for color, brightness and composition, then assembled into a Muse Image-format prompt. The goal is moving from intuitive prompting for style imitation to a draft grounded in reference-image analysis. Open source is the author's claim; no identifiable repository name or license text is provided.

The author says they actually ran the bundled flat-style rainy-night city silhouette example and generated another image with the returned prompt. Buildings, rain lines, an orange sign and a full moon reportedly remain in place, but windows are denser, the moon too bright and the bottom vertical lines look like a barcode. This is a single trial with reported defects, not exact recovery of the original prompt, general composition preservation or automatic reproduction of every style.

Retrieval confirms attribution. An author reply contains only a short link, not expanded here. The original image, actual input/output pair, generated prompt, model revision and replayable records were not technically checked. Neither the tool nor Muse Image was run here. The existing REA-Prompts entry describes generic templates; without a shared repository, the two are not assumed to be the same project. REA is unmentioned.
