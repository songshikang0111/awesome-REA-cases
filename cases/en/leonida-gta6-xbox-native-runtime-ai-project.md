At 11:27:26 Beijing time on November 23, 2026, lei'zi (@lis1091fu) introduces Leonida, saying work independent of the game executable is done, most PRs are Claude-coauthored and playability might precede an official PC release. This is a secondary introduction; the hardest part being over and the playability timeline are not acceptance results.

Earlier supplementary research pinned ItsNotRexed/Leonida at commit 3eb4410, dated November 23 at 11:56:15 Beijing time (03:56:15 UTC). The README describes static recompilation of Xbox Series GTA VI: both CPUs are x86-64, native code is loaded while console system software is reimplemented, precompiled RDNA2 shaders become Vulkan SPIR-V, and models, textures and audio come from an owned copy. It says the repository contains no game, keys or executable, supplies no acquisition instructions and neither decrypts nor bypasses protections. An already-readable, personally owned Xbox Series 1.0.2.1 package is required. This is the design, not verification of package authenticity or lawful provenance.

That pinned older version explicitly says Early, no boot and no story mode or any playability. The reported 26,503 shader translations and successful spirv-val runs at some revisions do not establish output semantics or full-game execution. Its hand-maintained table has duplicate, partly conflicting old/new wave64 and graphics-coverage rows, not reconciled here into a defect-free metric. Handwritten GPU tests are not game-shader output comparisons; PE loading/import shims only tested a stand-in executable. D3D12-to-Vulkan, some shader behavior, ray tracing and model decoding retain gaps. The commit credits Claude Opus 5.5 for static PE model-hash candidate ranking and synthetic tests. Earlier review read the message and filenames, not the full patch, establishing neither the share of PRs nor autonomous completion or all tests passing.
