ChatGPT infers reusable design rules from reference works instead of receiving vague requests for a premium look. The example extracts style DNA from three Laos-series covers and uses it for a Chiang Mai café cover.

The first prompt asks for analysis without generation, organizing shared composition/whitespace, type hierarchy, color, photographic treatment and mood. The second supplies a new theme and purpose, asking for three visual decisions translated into English image-generation prompts. The text also lists ten observation dimensions and suggests three to five references. Three is the example size, not proof that three images always recover a unique style.

This is a secondary tutorial with a specific reconstruction use case. It lacks the original designer's name, reference covers, new output, prompt responses and comparative evaluation.
