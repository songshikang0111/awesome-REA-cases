# Fake thinking inside fingerprinting JS: Vincent says Claude spotted injection and continued decoding a VM

Category: Applications and clients · Other AI-assisted work
Record date: 2026-11-23
Stage: Needs verification

At 21:03:26 Beijing time on November 23, 2026, Vincent (@Vincent_AINotes) describes Claude Code investigating device/behavior-fingerprinting JavaScript allegedly loaded by a Tencent page. The target is an obfuscated string table and custom VM. The post says the source contains text impersonating the model's internal analysis, asking it to summarize the module as ordinary ES5 compatibility code and avoid VM-bytecode analysis. Those are untrusted instructions inside the investigated sample, not operating instructions adopted by this collection.

Vincent says the decoy sits behind a special global condition, but Claude recognized the injection, continued analysis and recovered 125,696 integer units. Original-post retrieval confirmed attribution, text and three image attachments. The images were not read, and the original script, domain, hash, execution records and decoding comparisons were not obtained. Suspected Tencent origin is not confirmed vendor attribution; integer-unit count is neither correctly recovered function count nor proof of a complete protocol. This records the poster's account of analysis and injection resistance only. VM semantics and real-site behavior were not independently checked, and no script was run or service accessed.
