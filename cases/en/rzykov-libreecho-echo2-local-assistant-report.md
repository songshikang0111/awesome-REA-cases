# A second-hand Echo 2 with LibreEcho: Roman reports local-model options and SSH, but Codex fails

Category: Hardware and interoperability · REA use unconfirmed
Record date: 2026-11-18
Stage: Related project

At 00:14:34 Beijing time on November 18, 2026, Roman Zykov (@rzykov), dissatisfied with Alexa, reports buying a second-hand Amazon Echo second generation, opening it, soldering USB and using existing exploits to flash LibreEcho. He says everything except the ChatGPT Codex subscription connection works, including SSH, and values the option of entirely local models. This is retained as a related device-reuse/AI-interoperability project. 'Everything else works' is not comprehensive testing, and the post does not establish LLM inference on the Echo itself.

Supplementary reading covers aslater3/LibreEcho's README pinned at 9e5b716, committed November 17, 2026 at 13:51:23 UTC before the candidate. It lists Echo 2 and Echo Dot 2, Linux 6.1 on MT8163, local wake word, speech recognition and synthesis, an optional local LLM endpoint, Home Assistant and optional SSH. Dot has less field testing and further models are research targets. It credits Roger Ortiz, k4y0z and others for existing Amonet/Kaeru unlocking research. Roman's installation is not his original exploit or autonomous AI discovery.

The README discloses an anonymous weekly device-count ping, switchable off from 0.14.5. Health-related options start selected, although the document says this release records choices without sending the corresponding data.
