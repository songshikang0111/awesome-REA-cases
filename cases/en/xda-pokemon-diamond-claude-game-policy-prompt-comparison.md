# Pokémon Diamond prompt comparisons: XDA reportedly finds Claude declining recreation but willing to plan decompilation and a port

Category: Games and preservation · Other AI-assisted work
Record date: 2026-11-05
Stage: Analysis test

At 19:00:01 Beijing time on November 5, 2026, BT beartai (@beartai) posts a Thai account of XDA Developers' Claude game-rule research. Its named test target is Nintendo DS Pokémon Diamond. Asked to recreate the game, both Opus 5.5 and Opus 5 reportedly refuse. Version 5.5 invokes game-recreation rules; version 5 initially rejects decompilation and ROM porting, then offers lawful decompilation help after a follow-up.

The article further says Opus 5.5 agrees to assist decompilation of the same game, explain recovered code, rebuild from a user's own copy and create tools. Asked about native Windows execution, it outlines static recompilation: DS instructions to C, loading behavior and graphics/audio/hardware adaptation. Included as a conversation-based analysis test of a named AI-assisted reversing workflow, not recovered functions, ROM execution or a completed Windows port.
