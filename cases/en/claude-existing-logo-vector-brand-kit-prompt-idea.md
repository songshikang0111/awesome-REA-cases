# Recover a brand kit from existing logos: a Claude audit and vector-reconstruction prompt idea

At 22:11:40 Beijing time on November 13, 2026, a poster shares a prompt for Claude or another AI to turn a company's existing logo and brand files into a kit for a printer. All original files go in one folder. The model is asked to inspect formats, resolution and true vectors versus bitmaps, select the best source, extract HEX/RGB/CMYK colors and identify fonts or flag free approximations and guesses. It must stop after the audit for user approval. The goal is recovering existing visual specifications, not redesigning the logo.

Later steps request unchanged shapes, proportions and spacing; horizontal/stacked, icon/wordmark, full-color/black/white and embroidery-friendly simplified variants; and SVG, PDF and transparent PNG files in several sizes. Further assets include social images, business cards, letterhead, invoice headers, email signatures and signs, with a one-page usage guide and a ZIP. The prompt requires real company details, no invented taglines, honest disclosure of limitations and no fake outputs. No actual company, input files, color measurements, font comparison, vector output or print test is provided. Exact matching is a requirement, not a demonstrated result.
