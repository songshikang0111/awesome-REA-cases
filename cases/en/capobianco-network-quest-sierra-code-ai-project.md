# Network Quest: AI loops build a networking adventure inspired by reverse-engineered Sierra code

Category: Games and preservation · Other AI-assisted work
Record date: 2026-11-28
Stage: In progress

At 04:47:42 Beijing time on November 28, 2026, John Capobianco (@John_Capobianco) introduces Network Quest. After studying PC Globe 1987 and growing up with Sierra adventures such as King's Quest and Space Quest, he says actual reverse-engineered Sierra code inspires a networking-themed game built with Astra GPT 6.2, three.js, Blender and Audacity. This is not a complete port of a particular Sierra game. PC Globe is background to his earlier work; this post does not separately document its AI-reversing process.

Planning and implementation reportedly use specification-driven loops: ten each for constitution.md, spec.md and plan.md, thirty total, with 25 human clarification steps between specification and plan, producing 175 tasks. The recommendation was 200 Ralph loops including 25 slack loops. He reports two days of continuous looping, roughly five weekly quota resets consumed across two accounts, a current loop total of 47 hours 17 minutes and 1,599,685,368 recorded tokens. These are author counts without billing records, logs or a token-accounting definition, not reproducible cost or efficiency benchmarks.

Current work covers only the first level, The Physical Layer. Seven interconnected networking layers, Google/GitHub login for saved games, full open sourcing, a manual, maps and an ASCII walkthrough are plans or ongoing attempts. Source, reversing notes, task files and a playable build were not obtained; login, all levels and the extent of original-code use are not confirmed. Kept as an attributed in-progress project. No game was run and REA use is unconfirmed.

November 28, 2026 candidate snapshot: 4 likes, 392 views, 0 reposts, 5 replies. Duration, quota and token counts were not independently checked.
