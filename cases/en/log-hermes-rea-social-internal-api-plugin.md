At 01:56:09 Beijing time on November 13, 2026, matt. (@matthewsoldit) introduces log, aiming to let an agent find opportunities in users' existing conversations while freeing their time. He says log is already integrated into Nous Research's Hermes Agent as a plugin and is all open source. This records his project announcement, not an official Hermes feature guarantee.

He says log builds on @treg_ai, @subquadratic and @morluto's Reverse Engineer Anything to find internal APIs of social media or websites so an agent can take control.
