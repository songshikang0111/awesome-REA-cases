# SM64 tabletop diorama: a reported Claude port using Unity/PICO CLIs

Category: Games and preservation · Other AI-assisted work
Record date: 2026-11-01
Stage: Needs verification

At 02:22:00 Beijing time on November 1, 2026, Xiao Tan (@tvytlx) reports someone turning a Super Mario 64 level into a PICO-headset tabletop diorama in one weekend, claiming native 3D and stable 90 fps. The post specifically credits Claude Code/Opus 5.5 with connecting existing decompiled source to Unity rendering, converting N64 geometry, mapping MR controllers and fixing frame pacing. Unity CLI and PICO CLI reportedly enable terminal-based build, deploy and revise loops.

The post acknowledges n64decomp's prior work and says original ownership is needed for asset extraction. Original-ROM hash parity, weekend labor and 90 fps are that post's claims; no build, frame-time data or code was obtained. Its PICO/Unity account differs from the existing Vision Pro and other SM64 spatial demos, without confirmation of the same implementation, so platforms or verification are not merged. Original identity was not confirmed, a headset was not run and assets were not extracted. Retained as an unverified third-party port report.
