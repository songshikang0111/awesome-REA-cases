# Battlefield 1942 in a browser: further secondary claims of 57,000 functions and WebGL 2

Category: Games and preservation · Other AI-assisted work
Record date: 2026-11-03
Stage: Needs verification

At 23:48 Beijing time on November 2, 2026, dimash (@dimqshi) says levels had Claude Code decompile Battlefield 1942's 'C engine' and now runs it in a browser tab. The target is bringing the 2002 engine to the web. Abandonware wording does not terminate copyright or authorize distribution of the original game.

At 09:05 on November 3, Lanzhi AI (@LanzhiAI) further recounts levelsio using Claude Code/Opus 5.5 to handle 57,000 x86 functions and translate them into WebAssembly, replace DirectX 8 rendering with WebGL 2 and make browser multiplayer. The post also says an attempt half a year earlier was abandoned. This is not a verified project timeline or a labor measurement showing that one agent now completes everything. The 57,000 figure lacks a defined scope, code inventory or matching denominator; it is neither a match rate nor proof of original C recovery.

Original lookup confirms both accounts' attribution, but an original levels explanation, repository, build, demo URL, rendering/input/network tests and human-correction count were not obtained. Two early replies only ask whether Claude read Ghidra output and how much manual fixing was needed, without answers; a toolchain still cannot be inferred. The update adds specific secondary claims, not independent validation of multiplayer, a complete campaign, browser compatibility or freedom from original assets. The ID is retained and remains distinct from a generic Battlefield/Frostbite open-implementation idea. No game, web build or original assets were downloaded or run here.
