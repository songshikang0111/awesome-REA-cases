# Battlefield 1942 in a browser: secondary reports from 57,000 translated functions to version 1.61 cross-play

Category: Games and preservation · Other AI-assisted work
Record date: 2026-11-05
Stage: Needs verification

At 23:48 Beijing time on November 2, 2026, dimash (@dimqshi) says levels had Claude Code decompile Battlefield 1942's 'C engine' and now runs it in a browser tab. The target is bringing the 2002 engine to the web. Abandonware wording does not terminate copyright or authorize distribution of the original game.

At 09:05 on November 3, Lanzhi AI (@LanzhiAI) further recounts levelsio using Claude Code/Opus 5.5 to handle 57,000 x86 functions and translate them into WebAssembly, replace DirectX 8 rendering with WebGL 2 and make browser multiplayer. An attempt half a year earlier was reportedly abandoned. This is not a verified project timeline or a labor measurement showing one agent completes everything. The 57,000 figure lacks defined scope, inventory or matching denominator; it is neither a match rate nor proof of original C recovery.

A new candidate at 14:15:00 on November 5 describes disassembling the demo's x86 code, translating functions into about 100,000 lines of C, generating Wasm with Emscripten, rewriting about 300 Windows/Direct3D interfaces and adding WebSocket networking. Its instruction-to-READ32-expression example describes machine-code semantics translation and compatibility layers, not recovery of original human-written C. The post claims a later upgrade to the 2004 version 1.61, browser players sharing servers with original clients, iPhone/Android support and up to 64 players. These remain secondary claims; 'official server' is not treated as EA endorsement. It acknowledges portrait mode crops arms and vehicle interiors and that the creator still does not know the aircraft controls; complete input/rendering correctness cannot be inferred.

Retrieval confirms the first two reporters' identities, but an original levels explanation, repository, build, demo URL, rendering/input/network tests and human-correction count were not obtained. Early questions about Ghidra and manual repairs remain unanswered; a toolchain is not filled in. These are specific secondary claims, not independent validation of multiplayer, a full campaign, browser compatibility or independence from original assets. The ID is retained, distinct from the generic Battlefield/Frostbite open-implementation idea. No game, web build or original assets were downloaded or run here.
