# A BLE-to-MCP bridge: QloveDudu reuses Toy-Relay and sosexy protocols in an agent-assisted setup framework

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-11-03
Stage: Related project

At 07:15 Beijing time on November 3, 2026, @QloveDudu introduces an open integration framework for adult BLE devices: MCP connections from official apps, Telegram bots or custom frontends; a phone Bluetooth relay; handwriting/voice-to-control mapping; local sound-event recognition, feedback buttons, replay and three panel themes. Only the interoperability architecture is recorded here, without adult-use detail. The author says repository onboarding prompts can guide Claude Code or Codex through setup; the open edition is a blank framework, free for noncommercial use.

Attribution is explicit: the cloud-plus-phone relay design and Bobobei protocol come from Toy-Relay (@miao_tutu), with original protocol reversing credited to sosexy-ble-control. Retained as a related project connecting AI tools to previously reversed protocols, not a claim that this author or Claude newly recovered BLE behavior. The author says recognition stays on the phone and only events are sent, while voice synthesis uses ElevenLabs. Local recognition does not make the full system offline or privacy-audited.

A confirmed repository for this specific project, its license, code and support matrix were not obtained. No device, agent or safety default was tested.
