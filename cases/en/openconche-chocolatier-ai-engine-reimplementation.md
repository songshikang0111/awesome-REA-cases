# OpenConche: AI-assisted research of four Chocolatier games, a new engine using original assets

Category: Games and preservation · Other AI-assisted work
Record date: 2026-11-17
Stage: Needs verification

At 11:00:39 Beijing time on November 17, 2026, The Gaming Emporium (@McGroin83) introduces open-conche's OpenConche v1.1, reporting extensive AI-agent involvement in reversing, implementation, review and testing to run 2007–2009 Chocolatier business games on Windows, Linux and macOS. After retrieving the complete post, supplementary research located the public repository and read its README at f82158242e44ad0d55b0ac1dd61ee48fd75c0403, committed November 14 at 06:37:12 Beijing time. That is pre-window supporting evidence.

The README explicitly describes a few weeks of AI-driven development against original binaries and scripts, rebuilding an engine in C++20/SDL3. docs/re stores fact files and docs/design design reasoning; individual research files and implementation were not audited here. Four supported titles are Chocolatier, Chocolatier 2: Secret Ingredients, Chocolatier: Decadence by Design and The Great Chocolate Chase. Big Splash Games made the first three; Zemnott developed the spin-off, published by PlayFirst, so all four are not attributed to Big Splash. They share one engine project rather than four separate cases.

The stated motivation is old programs no longer running on modern macOS, Windows display-driver compatibility and poor scaling of original 800×600 output. The README reports native-resolution fonts while artwork still scales from its original resolution, a built-in game finder, saves separate from the originals and distinct third-game/Reforged content. Users must supply original assets. MIT covers the new engine, not distribution or relicensing of original material. The author explicitly calls it an as-is hobby project without a roadmap or support commitment; other PlayFirst titles do not work automatically.

The post names v1.1, but release tags, platform builds, full-game tests and visual equivalence were not checked. No binaries, assets or dependencies were downloaded, game run or screenshots viewed. AI model and REA use are unspecified; a few weeks is a rough author development period, not transferable labor accounting. Status remains unverified for this publicly documented project report.
