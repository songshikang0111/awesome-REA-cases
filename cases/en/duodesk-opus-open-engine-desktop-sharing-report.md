# DuoDesk: Opus adapts an open sharing engine, not verified TeamViewer reverse engineering

Category: Applications and clients · Other AI-assisted work
Record date: 2026-10-31
Stage: Needs verification

At 22:29:42 Beijing time on October 31, 2026, Movez (@0xMovez) reports building DuoDesk with Claude Code/Opus 5.5 for shared Windows PC/MacBook mouse, keyboard, clipboard and cross-screen files, also advertising old-laptop/tablet second displays, no account, no cloud and encryption. The headline claims TeamViewer/AnyDesk reverse engineering, but the steps begin by supplying an unnamed open-source screen-sharing engine, reading its Windows, Mac, Linux, Android and native input-helper code, then rebranding roughly 370 files with 11 parallel agents. One agent decides what must not be renamed to retain pairing compatibility. Adapting existing open code is not recovery of every protocol from proprietary binaries.

The author describes tag-triggered GitHub Actions for .dmg, .exe, AppImage, .deb and .apk installers, with Mac builds on cloud Apple hardware. An initial cursor crossing stalled at the Windows edge; Opus reportedly read logs, found the cause and added explicit crossing-refusal logs. A test deployment also took down the live website, reportedly rolled back in 20 seconds before agents lost deployment permission. Two days, zero personally written lines and recovery time are author figures, without workflow runs or logs as evidence.

At 23:49:46, the same named DuoDesk workflow appears again, adding remote-app windows, phone calls/texts/notifications/camera bridging and Wi-Fi, USB and Bluetooth claims. It supplements this entry rather than creating another project; those additions were not individually tested either. The first author's identity was checked, but no video was watched, upstream identified, pinned code obtained, installer inspected or two-computer test run. Encryption/no-cloud claims are not security audits, and website rollback does not validate complete app compatibility. Retained as unverified AI-assisted open-engine adaptation. REA is unspecified.
