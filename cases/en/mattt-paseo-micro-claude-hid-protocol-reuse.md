# Paseo Micro: Mattt uses Claude and an already-reversed USB HID protocol to control coding agents

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-11-03
Stage: In progress

At 08:17 Beijing time on November 3, 2026, Mattt (@mattt) introduces the Paseo Micro plugin and macOS app, turning a Work Louder Creator Micro 2 keypad into a controller for Paseo coding agents. After about a month using Paseo, noticing which agent needed attention became the bottleneck. He bought the keypad and enlisted Claude.

He explicitly credits @chacon's micro-manager with reversing and documenting the USB HID protocol. Building on it, he reports a working plugin within an hour and a week of polishing. A translucent key glows green when an agent is waiting; tapping opens that conversation even from the background. A double-wide key provides push-to-talk, alongside back/forward navigation, dial scrolling and a joystick response menu. About 90% of his use is the next-agent key and dictation: a personal usage share, not measured productivity improvement.

Original lookup confirms attribution and the full account. The author explicitly labels the picture AI-generated from his keypad photos, so it is not hardware-function validation. No confirmed project repository or device execution was obtained here; the hour, week and input behavior remain author reports. This is AI-assisted reuse of prior protocol research, not protocol discovery credited to Mattt or Claude.
