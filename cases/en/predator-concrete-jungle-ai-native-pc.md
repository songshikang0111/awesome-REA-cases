# Predator: Concrete Jungle: an Xbox PC port mixing static recompilation and decompiled C++

Category: Games and preservation · Other AI-assisted work
Record date: 2026-11-10
Stage: In progress

At 16:30:16 Beijing time on November 10, 2026, yibie's list update names Predator: Concrete Jungle, rebuilding Eurocom's 2005 original Xbox game for PC. Supplementary reading identifies Adolini1715/Concrete-Jungle-PC and its README: statically translate the Xbox program to C, compile for x86-64, and replace selected functions with decompiled, modified C++. The goal is native play on modern PCs, not whole-console emulation.

Documentation says users build from their own US retail disc. The installer checks the default.xbe version and uses xboxrecomp plus Concrete-Jungle-Decomp; original game code and data are not in this repository. Listed features include Windows and Linux, OpenGL 3.3, up to five-times internal resolution, a 60 fps option, modern camera/controller/keyboard/mouse controls, quick saves and loads, and some hand-redrawn UI. The author warns that no official prebuilt downloads exist and users should not run someone else's pcj.exe. Features are project claims, not hardware checks here; installer and dependency verification were not audited.
