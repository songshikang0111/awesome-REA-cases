# Meridian Family: Android local models, Termux and APK decompilation in one toolkit

Category: Applications and clients · REA use unconfirmed
Record date: 2026-11-02
Stage: Related project

At 09:32:11 Beijing time on November 2, 2026, Alen Požun (@termuxSolutions) introduces the Master version of Meridian Family, combining five apps. The author says Android background and toolchain restrictions led to using the Termux Linux environment with ADB for Android access. Features include downloading local models, switching between small and large models by task, building and signing one's own apps, decompiling APKs and invoking other Termux capabilities. The inclusion concerns this combined AI/APK-research workbench, not reported reversing of a named app.

The author claims 100% offline defaults without accounts or cloud, with provider requests only after voluntarily enabling online mode and supplying one's own API key. They say every function works, describe partial open source and a C++/Kotlin/Java/Python/HTML implementation, and call the video a teaser that does not yet show Meridian Core or NullCloud. Original-post lookup confirmed attribution; XDA/GitHub short links, implementation and video verification were not inspected. Offline, security and completeness claims were not traffic- or code-audited; Termux being open source does not make the system 'bulletproof'. REA and the decompiler engine are unspecified, with no assumption of permission-free operation or universal APK support. No app was installed, phone connected or API credentials accessed.

Candidate snapshot: 2 likes, 131 views, 1 repost. Five-in-one, default-offline behavior and all-functions-working are author reports.
