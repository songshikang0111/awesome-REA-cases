# iPhone Mirror on Windows: an Opus reconstruction claim and WDA control limits

Category: Applications and clients · Other AI-assisted work
Record date: 2026-11-09
Stage: Needs verification

At 01:22:13 Beijing time on November 9, 2026, @0xCodez claims to have reverse-engineered MacBook iPhone Mirroring for Windows with Opus 5.5. The concrete path described is a floating phone window on Windows selected through the iPhone Control Center's Screen Mirroring feature, reportedly with audio and up to 60 fps. Optional USB, iTunes and WebDriverAgent (WDA) provide taps, swipes, scrolling and typing.

The post mentions sideloading WDA with Sideloadly and an Apple ID, trusting the app, enabling Developer Mode and using Ctrl+U for control. These are reported setup requirements, not instructions executed by this collection. System screen mirroring plus WDA does not alone establish recovery of the proprietary protocol, locked-phone behavior or complete feature set of Apple's native Mac iPhone Mirroring.

Retrieval confirms attribution and wording, but no pinned source, protocol investigation, build record, supported-device list or latency/frame-rate measurement was obtained. Sixty fps is a claimed upper bound, not a benchmark. No install.bat was run, app sideloaded, phone connected or credentials submitted here. REA is unmentioned; retained as an unverified alternative-implementation report.

Sealed snapshot: 48 likes, 2,238 views, 2 reposts. Model and up-to-60-fps claims are the author's wording, not measurements here.
