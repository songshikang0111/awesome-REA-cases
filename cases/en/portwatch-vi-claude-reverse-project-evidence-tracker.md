# PortWatch VI: Claude-assisted repository reading and claim tracking for GTA VI ports

At 15:00:01 Beijing time on November 27, 2026, Kaiku (@kaikubuilds) introduces 4lwayz/portwatch-vi in a tool roundup: a common progress ladder for community GTA VI recompilation, emulation and PC-port efforts. Its purpose is to reduce repeated repository checking and confusion between fake installers, author claims and demonstrated progress. Supplementary reading pins README to commit 54eb2fa8091ee27f47f584c066821825b45c9bb3, dated November 27, 2026 at 15:37:54 Beijing time. It postdates the candidate and is supplementary project documentation, not a second window candidate. The docs describe a static GitHub Pages site refreshing repositories, README changes and public leads every three hours, with groundwork, blockers, candidates and fake-download warnings. Executable runs, first frame, menu, in-game, 30 FPS and stability occupy ladder positions 25, 40, 55, 70, 85 and 100. These define editorial scoring; they do not show that those milestones have been achieved.

The documented AI component is optional Claude review: with API configuration, Claude, named claude-opus-5-5 in the docs, reads changed READMEs and recent commits, re-scores tracked efforts and promotes or rejects new candidates. The project says GTA VI milestones count only when backed by quotations actually present in the repository, groundwork can rise at most 0.3 per run, and reviews are capped at twelve per run, with a rough cost estimate of $0.05–$0.20 each. Without configuration, keyless discovery still runs but candidates wait for review; automatic refreshing must not be equated with AI review on every run. Docs also describe Claude searching and writing short news articles and a daily editing route on the maintainer's PC. None was executed here.

The project explicitly calls scores editorial estimates based on public READMEs, commits and issues and labels self-reported claims unverified. The countdown expresses an expectation, not a guaranteed release date, an existing executable or verified playability. README promises not to host or link game files, keys or executables, but this collection did not audit the complete site output or every external link; that promise is not a completed security audit. Review was limited to the attributed post and pinned docs. The scout implementation, model sessions, scoring accuracy and actual launches of tracked projects were not checked. No site was run, dependencies installed, game downloaded or API configured. The candidate's 5,754 stars and 1,314 added in one day were not checked against GitHub history and are not evidence of quality or successful reverse engineering.
