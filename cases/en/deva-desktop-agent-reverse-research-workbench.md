# Deva: a separate desktop agent workbench for reversing and specialized prompt configurations

Category: Applications and clients · Other AI-assisted work
Record date: 2026-11-28
Stage: Needs verification

At 16:22:16 Beijing time on November 7, 2026, Kxians (@xulijian1994) introduces the Deva desktop agent workbench, claiming OpenAI/Anthropic model protocols, multiple roles, MCP, skills, subagents, tool calls, scheduled tasks and code rollback. The stated motivation is to keep everyday work in Claude Code/Codex while putting reversing, security research and specialized prompts in a separate application rather than mixing configurations into production development.

The post attributes bundled prompts to DSH-Purge and names DeepSeek, Kimi, GLM and Qwen. These are the introducer's capability and applicability claims, not proof that model restrictions are bypassed. Retrieval confirms attribution, but GitHub appears only as a short link; a confirmed repository, license, platform, code and research sample were not obtained. A separate desktop app does not establish OS-level isolation, permission enforcement or safety, and code rollback does not make external actions reversible.

At 12:10:15 Beijing time on November 28, Isk Mashiro (@iskunzhenbai) introduces a similar harness, explicitly naming Deva as the default general role and Xiaomajiang as the reversing role. Claimed features include OpenAI/Anthropic cache breakpoints, task planning, scheduled tasks, subagents, checkpoints, MCP, IM notifications, multiple windows and AI-customized roles. The tool introduction is merged on the Deva role name and matching capability description rather than creating another duplicate workbench. Without a checked repository, version continuity and each implementation remain unconfirmed. Thread replies mostly express approval, not independent tests.

Retained as an unverified introduction to a concrete research tool, without a named target's decompilation, repair or successful jailbreak result. Deva and its prompts were not installed, run or tested here. REA use is undisclosed.
