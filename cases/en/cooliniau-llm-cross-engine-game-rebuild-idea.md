# Change engines to make games easier to mod: Cooliniau's LLM rebuilding idea and terminology correction

Category: Games and preservation · Other AI-assisted work

Stage: Needs verification

At 09:21:37 Beijing time on November 23, 2026, Cooliniau (@cooliniau, signing ini) suggests a different kind of LLM-assisted decompilation: rebuilding a game one-for-one in Unreal, Unity or Godot, both as a reference and to make modding easier. No original game, source engine, input material or model is identified. The concrete idea is cross-engine behavior reconstruction for modifiability, not a project already undertaken.

Supplementary author replies at 09:23:12, 09:35:38 and 09:37:15 in the same thread question the word decompilation. The author tentatively calls these wrapper decomps, distinguishing them from source decompilation whose source can be edited directly. Unreal, Unity or Godot would still be a middle layer to handle, although the reconstruction could offer fangame developers and frameworks a more direct reference to the original. This correction is preserved: one-for-one is a goal, not proven equivalence, and no formal technical taxonomy is imposed on the author.
