# Craft Anything: a Rust study-and-rebuild workbench with explicit limits on project-reported checks

Category: Applications and clients · Other AI-assisted work
Record date: 2026-11-09
Stage: In progress

At 09:51:48 Beijing time on November 2, 2026, Smartpig (@Smartpigai) introduces Craft Anything studying websites, apps or games, then having AI build and compare iterations. At 11:15:23 mingzi206 (@mingzi206) promotes full automatic hooking, symbolic-execution architecture graphs and completion in minutes. Earlier supplementary review read README/STATUS at 32b80be89061896921d370e8f4f952ab707e2270, committed November 2 at 11:40:37; its October 18 runs and October 23 audit are older. The pure-Rust workbench then claimed 314 CLI/MCP tools, 298 in the engine. Later counts do not overwrite that revision.

Default Clean room observes visitor-visible interfaces, user images and descriptions, not internals; Deep permits code, files, website JavaScript and optional Ghidra. Building favors Claude Code, while analysis can use APIs or local compatible services. Clean room is a mode name, not legal certification or an OS sandbox. Older pinned documentation's lack of real-installation Codex verification is historical, not a reason to erase subsequent actual user runs.

STATUS reports October 18 Windows headless website likeness of 96% in 1.5 minutes; a small desktop app in nine minutes checked only by building; and a Rust game stopped at Build before Check. Likeness is not functional equivalence and generated self-tests are not independent gameplay validation. Older runtime study launches the original once for a window/UI tree, not sustained interaction. Frida sessions are partly simulated and no complete live Clean room build is recorded. Every-syscall/memory-transition recording or arbitrary cloning in minutes is unsupported. A November 6, 17:23:57 secondary post claims 320 tools and three-width comparison without a pinned revision, widths, target or result; it establishes neither six new features nor backend equivalence.
