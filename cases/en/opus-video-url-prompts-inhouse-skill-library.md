# Video URLs to an in-house style library: shreyvijayvargiya reports Opus prompt inference and almost 10,000 skills

Category: Applications and clients · Other AI-assisted work

Stage: In progress

At 20:44:12 Beijing time on November 10, 2026, shreyvijayvargiya (@treyvijay) describes an internal workflow that infers video prompts for Claude Code generation. The aim is extracting similar looks, patterns, themes and styles from references for an in-house inspiration library, not reverse-engineering video-platform software.

The author says the team first aggregates top video-generation skills across domains, then uses Opus to build a URL-to-prompt-and-skill API for YouTube, TikTok, Instagram, X and Threads. An intermediate harness layer uses randomisation and context understanding to generate skills with different tastes but similar styles. Almost 10,000 prompts/skills reportedly have been collected. That wording is retained rather than interpreted as 10,000 distinct videos, original prompts or validated skills.

Retrieval confirms attribution and text. API documentation, code, input clips, output comparisons and permissions were not inspected. Quality, cost, platform coverage and availability are unverified. Inferred prompts are not necessarily original prompts; an internal library is not a public service, and REA use is not established.
