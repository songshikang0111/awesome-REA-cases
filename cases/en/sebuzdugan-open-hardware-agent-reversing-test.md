# Open schematics are not device understanding: Sebastian's agent hardware-reversing experiment

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-11-18
Stage: Analysis test

At 20:25:35 Beijing time on November 18, 2026, Sebastian Buzdugan (@sebuzdugan) says he tested whether coding agents could use open hardware designs to reverse-engineer devices more effectively. The question is whether schematics, documentation and public designs automatically give agents an engineering advantage.

His qualitative conclusion is that access to information is not knowing how to use it: agents still need to interpret designs, identify components, understand connections and reproduce hardware correctly. Cheaper access to reversing material does not automatically improve model competence. No device, model, task count, success rate or control setup is supplied, so this does not establish that open hardware is useless or that all models fail.
