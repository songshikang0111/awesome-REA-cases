# An iPad mini 7 recovery: Zhuoli Li credits Codex with studying WiFi recovery and erasing without a wired upgrade

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-11-05
Stage: Needs verification

At 16:27:03 Beijing time on November 5, 2026, Zhuoli Li (@DreamingPiggy) reports an iPad mini 7 running iOS 18 stuck in a boot loop after using Nugget's extended-display feature, with suspected system-file damage. Other advice called for a wired restore and upgrade; the author wanted the device working without a forced OS upgrade. The cause remains the author's suspicion: no system logs establish that Nugget caused it.

The author explicitly credits Codex with finding built-in WiFi recovery, described as normally requiring another iPhone and exposing only an upgrade in its UI. Researching the transport protocol reportedly allowed an erase command outside that UI and successfully recovered the device. At 16:31:26 the author links generated code and steps; at 16:55:53 the author says retaining versions matters for iOS 18–26 fault/jailbreak recovery and that iOS 27 has an on-device Recovery Mode erase UI. These are supplementary same-window statements, not a compatibility matrix verified here.

Erasing clears data; this is not lossless unbricking, data recovery, downgrading or Activation Lock bypass.
