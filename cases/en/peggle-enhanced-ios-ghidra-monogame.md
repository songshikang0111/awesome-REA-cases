# Peggle Enhanced: Ghidra investigation of iOS code into C# and MonoGame

Category: Games and preservation · Other AI-assisted work
Record date: 2026-11-10
Stage: In progress

At 16:30:16 Beijing time on November 10, 2026, yibie's candidate lists Peggle Enhanced and highlights its FAQ limiting AI use to game code. Reading the public list identifies aidrum/peggle-enhanced; its README credits aidrum and TheAwesomeBlue. Old Android Peggle has audio and installation problems on modern phones. Building on the mobile SexyAppFramework ports in PlantsVsZombies.NET and Bejeweled Plus, the authors say they decompiled iOS Objective-C code with Ghidra, migrated it to C#, then fixed and expanded it in MonoGame.

Documentation describes native Windows, macOS, Linux, Android and iOS versions, including Peggle, Nights, Extreme and World of Warcraft adventures, with separate phone and HD tablet apps. Mobile is the main target; original PC releases are still recommended on PCs. The FAQ says AI was used only for game code; graphics edits, icon remakes, music additions and the README were manual. No model or REA use is established, and assets must not be called AI-generated.

The authors report beating every adventure on a Redmi Note 13 Pro 5G with Android 13; some older Android devices were tested only briefly on a few levels. They also list iPhone 17/iOS 27.0.1, tablets and a laptop, and say they compared behavior with an original iPad 3 and iPhone 4S. These are project tests without per-level logs or comparison images inspected here. Builds and the authors' belief that games are completable are not this collection's validation across all platforms. The candidate's 22 stars and 2,117 files were not recounted. README was read as supplementary material on November 10; its original update date is unconfirmed, not evidence of new in-window tests. No releases or game assets were downloaded, installed, built or played. Linked content retains its original rights.
