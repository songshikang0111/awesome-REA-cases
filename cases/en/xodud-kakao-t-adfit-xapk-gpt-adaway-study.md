# Kakao T ad rules: XODUD reports web-chat GPT studying AdFit hosts inside an XAPK

Category: Applications and clients · Other AI-assisted work
Record date: 2026-11-07
Stage: In progress

At 18:55:53 Beijing time on November 7, 2026, XODUD (@xodud_rkd) seeks an AdAway ad-filter list for Korean mobility app Kakao T. The author says they dropped its XAPK into ordinary web chat with GPT-6 Astra Pro, without extra instructions, custom tools or Codex setup. The model reportedly unpacked it, studied the AdFit SDK and found actual request hosts encoded as integer arrays rather than only generic Kakao ad domains, including US and Japan variants.

The author reports a hosts file with nine enabled rules, reward-ad filtering left optional to preserve point offers, and two Kakao T CDN rules set aside. Work was still ongoing, with a full list promised later. Rule count is not a count of successfully blocked requests and does not establish unaffected rides, rewards or networking. Speculation that Opus would not do this is not a comparative model experiment.

Retrieval confirms attribution and four images, but screenshots were not read. Complete rules, app revision, sample hash, model output, traffic and before/after tests were not obtained. The host short link was not expanded and unverified filtering domains are not republished. REA is unmentioned. No APK was obtained, hosts file changed or service contacted here.
