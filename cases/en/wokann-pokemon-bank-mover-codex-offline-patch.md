# Pokémon Bank/Mover: Wokann's public Codex-assisted offline patch does not support HOME transfer

Category: Games and preservation · Other AI-assisted work
Record date: 2026-11-01
Stage: In progress

At 23:09:04 Beijing time on November 1, 2026, Trey Gwn (@treygwinn), discussing Wokann's Pokémon Bank offline patch, credits Codex with reducing production time. He says it appears work began in August and shipped in three months, and claims Bank closes in four months. These are a commenter's timing inference and shutdown claim, not an official schedule or controlled AI-efficiency comparison verified here. The additionally read parent conversation includes Professor Rex's October 31, 22:00 release account: downloading existing online Pokémon as a backup, 3DS deposits/withdrawals, offline Poké Transporter and old Mystery Gifts. That parent predates the candidate window and is background only.

The README of Wokann/bank_and_mover_offline_patch was additionally read at pinned commit c709ec4d28cda0d7935b9ac11bc256e5b841e468, dated November 1 at 19:05:24 Beijing time, before this window. The project explicitly discloses AI tools including OpenAI Codex for analyzing decompiled output, designing patches, coding and review. Its purpose is continued local use of Pokemon Bank and Poke Mover/Transporter on Nintendo 3DS. In Offline Mode a local fake server answers requests originally sent to official services; the documentation explicitly calls this a custom community architecture, not the official server's design.

The documentation describes local storage, box organization, multiple users and configured gift replays. Mover transfers supported Gen5 and VC Gen1/2 saves into the local Bank. The official Bank can be downloaded while its service is available, but local data cannot be uploaded directly back. Pokémon HOME transfer is unsupported, and officially accepted tracker IDs cannot be forged. Server screening only simulates community-documented rules rather than reproducing all official checks. Selected old VC conversion and Chinese-encoding options are disabled by default and limited in scope, not complete compatibility across every generation.

The README requires Bank/game-save backups, supported v1.5 base applications and Luma3DS. Original decrypted/decompressed code, ExHeader and RomFS inputs must be legally obtained by users and are not distributed. It also warns forced unlocking of a mismatched save may lose Pokémon from the last unfinished transfer. Public documentation and AI disclosure provide inspectable implementation context, not proof of lossless saves, official-rule equivalence or security auditing. No original title was downloaded, patch built, 3DS run or independent retest performed here. REA is not mentioned.
