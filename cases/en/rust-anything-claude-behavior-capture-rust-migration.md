# rust-anything: capture old answers before Claude Code rebuilds slow paths in Rust

Category: Applications and clients · Other AI-assisted work
Record date: 2026-11-22
Stage: Needs verification

At 08:21:03 Beijing time on November 18, 2026, codila (@0xCodila) introduces rust-anything: run an old program on ordinary and edge inputs, record its answers, then have Claude Code migrate pieces into Rust with the old API and behavior checks. This extracts runnable behavior, not original source from closed binaries. The 08:31:36 reply then says file writes are checked but network/database calls are unsupported. The original project benchmark uses a ten-core Apple M4, 16 GB, macOS 27.3, Node 24.15.0 and Rust release builds, two runs, outputs compared before timing. Warmed in-process calls on the same set are 4.2x, not universal 19x or an automatically rerun benchmark after new cases. The standalone doc printer is slower across the bridge. Earlier docs also limit gate to port.rs, require manual dependency-crate checks and note that app replay without --build replays the original command without a fallback rate; this entry does not establish all such limits were later removed.
