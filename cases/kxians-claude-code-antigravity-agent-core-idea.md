# 给Antigravity改Agent内核：从Claude Code架构建议到REA研究竞品的idea

分类：应用与客户端 · REA
记录日期：2026-11-20
阶段：待验证

2026年11月19日19:00:52（北京时间），Kxians（@xulijian1994）认为Gemini模型能力已足够强，但Antigravity的协作体验拖累模型表现，因此建议Google找工程师逆向Claude Code，给Antigravity做一次内核移植。他的目的在于重建编程Agent的协调与交互架构，不是移植模型权重。
