# GROWBLOX与Growtopia：Zlatan转述Claude辅助直播开发并质疑相似度

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-11-08
阶段：待验证

2026年11月8日22:38:54（北京时间），Zlatan（@ZlatanRoblox）讨论ExecutiveStudio在Roblox上的GROWBLOX，称它与Ubisoft的Growtopia在世界选择界面、方块与建造系统、背包／快捷栏及多人玩法上相似，并说开发者据报在直播中展示Claude AI与逆向技术参与开发。具体目标是已有方块建造游戏式功能在Roblox上的重建，不是已证明取得Growtopia源码。

帖子还称有4000余活跃玩家、650万访问，并要求相关方调查。这些是作者当时的数字和质疑，没有独立平台快照、直播链接、代码、分析步骤或开发者说明；本合集未观看直播，不能确认哪些部分由AI研究或实现，更不据相似与热度认定侵权、授权或成功复刻。

11月9日补取确认署名和全文。按具名项目的未核验二手报告保存，保留争议归属，不把转述当独立复现；REA未提及，未启动Roblox游戏。
