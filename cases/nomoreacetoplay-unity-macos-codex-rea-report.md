# Unity 2D游戏上Mac：Codex与REA替换依赖并把DX shader转Metal的自述

分类：游戏与游戏保存 · REA
记录日期：2026-10-31
阶段：待验证

2026年10月31日17:10:51（北京时间），Bocchi calls Saul（@nomoreAcetoplay）回答Mac运行Windows游戏的问题，称Unity 2D游戏可让Codex协助套Wine和dxmt，3D是否可行不清楚。随后作者报告自己改用Codex加REA，把Unity等依赖替换为Mac原生版本，再套Unity player启动，连DX shader也翻译成Metal。目标是让现有Windows Unity游戏在Mac上使用原生依赖运行，不是从零重写Unity引擎。
