# CyberBinGym：补丁二进制帮助Agent恢复漏洞，但88%恢复不等于20%利用

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-11-11
阶段：分析测试

2026年11月11日09:01:59（北京时间），心有猛虎（@zg0820）介绍CyberBinGym：研究补丁发布后，AI能否从新旧二进制差异恢复漏洞并在受控服务完成利用，而非只解释代码。10:41:46的另一候选补充六类漏洞、三档分析复杂度与人工轨迹审查；11:32帖与该帖全文相同，不算新实验。

补查论文arXiv:2611.10723v1的摘要与提交记录，作者为Lambang Akbar Wijayadi、Zhaoqi Xiao、Zhun Wang、Hongwei Li、Wenbo Guo、Heng Yin、Zhenkai Liang、Dawn Song。v1提交于11月7日13:31:11 UTC，即北京时间21:31:11，早于本窗口；候选称11月10日发布，不能用转载口径覆盖原始提交日期。这里只阅读摘要页，未读全论文、任务实现或运行轨迹。

摘要确认100题来自53个常用项目的真实漏洞，覆盖六类和三档；提供stripped漏洞版与修补版二进制，不给源码与漏洞信息，要求结合静态和动态分析。评价把差分崩溃测试的漏洞恢复与取flag的端到端利用分开，并审查轨迹排除reward hacking。摘要报告最强Agent恢复88%、利用20%；在匹配的20题子集，加补丁使利用率由10%到25%；对原先成功的20题启用标准二进制加固后仍能利用两题。这些分母和实验条件不同，不能混成全体任务的通破率。

候选将三组分别归为Codex／GPT-5.6的88%与20%、Claude Code／Opus 5的85%与6%、Kimi Code／K3的64%与0%。摘要未逐项列模型，所以具体配置与后两组仍只按候选报道归因，未核论文表格。候选还称提供运行依赖、分析工具及受控victim，不给参考PoC或补丁源码；这里的“不给补丁”不是不给修补后二进制。研究不证明任意生产目标都可利用，也不排除开源项目训练先验。REA未提及，本合集未执行漏洞样本、连接victim或复跑利用。
