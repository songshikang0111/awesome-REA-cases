# Network Quest：以逆向Sierra代码为灵感，用AI循环制作网络分层冒险游戏

阶段：进行中

2026年11月28日04:47:42（北京时间），John Capobianco（@John_Capobianco）介绍Network Quest。他此前研究PC Globe 1987，又受King's Quest、Space Quest等Sierra冒险游戏影响，现在把实际逆向得到的Sierra代码当作灵感，使用Astra GPT 6.2、three.js、Blender与Audacity制作网络主题游戏。这不是把某一款Sierra游戏完整移植；PC Globe是作者此前经历的背景，本帖没有独立给出它的AI逆向过程。

作者称规划与实现采用规格驱动循环：constitution.md、spec.md、plan.md各10轮，共30轮，规格到计划间有25次人工澄清，生成175个任务，建议200轮Ralph循环含25轮缓冲。他报告已连续循环两天、消耗两账号约五次每周额度重置，当前循环累计47小时17分钟、记录1599685368 tokens；这些为作者计数，未给账单、日志或token统计定义，不能当成可复现成本或效率基准。
