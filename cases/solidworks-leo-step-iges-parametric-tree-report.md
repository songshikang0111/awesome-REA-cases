# SOLIDWORKS LEO：官方称从STEP／IGES恢复可编辑参数特征树

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-11-09
阶段：相关项目

2026年11月9日22:21:00（北京时间），SOLIDWORKS（@SOLIDWORKS）官方账号介绍AI Virtual Companion LEO：将导入的STEP或IGES文件转为原生可编辑SOLIDWORKS特征树，把静态BREP边界表示几何变成参数化模型。目标是研究供应商旧零件时不用从空白草图开始，继续调整特征、尺寸和设计意图。

补取原帖确认发布主体与措辞；这是产品方能力介绍，不是本合集操作演示或第三方验证。没有读取技术文档、版本／可用范围、支持的特征集合、输入零件、输出工程、失败情况或几何误差；未观看附件。生成可编辑树不证明恢复原作者真实建模历史或设计意图，也不保证复杂装配、任意STEP／IGES或制造公差。与SolidCraft替代CAD项目不同；REA未提及，本合集未运行SOLIDWORKS或LEO。
