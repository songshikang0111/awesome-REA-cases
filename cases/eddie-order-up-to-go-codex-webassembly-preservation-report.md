# Order Up!! To Go离开鼓包iPad：Eddie称Codex把32位老游戏移植到WebAssembly并模拟旧服务

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-11-16
阶段：待验证

2026年11月16日10:29:14（北京时间），Eddie Monteiro（@TheOnlyOtherEd）说儿子保留一台第一代iPad，只为玩Order Up!! To Go这款32位老游戏。作者称游戏已不再在iOS或Android提供／维护，设备电池鼓胀到撑裂屏幕，因此需要摆脱旧设备，又不想放弃游戏。这些发行与设备状态按作者归因，未另核商店历史。

受@levelsio将Battlefield 1942带到网页的工作启发，他问Codex能否对该游戏这样做，报告其反编译并转成WebAssembly，达到网页完整可玩。最初严重掉帧，于是要求持续优化直到浏览器中整款游戏至少30fps，称Agent连续工作两天。帖子没有明确列最终帧率、测试设备或逐场景结果，因此30fps只记为目标，两天不是本合集测得的工作量，‘完整可玩’也是作者判断。不能据此认定恢复原始源码或功能完全等价。
