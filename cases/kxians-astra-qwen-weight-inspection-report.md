# Qwen权重检查：Kxians转述Astra修改MLP缓解重复，并识别模型语言

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-11-03
阶段：待验证

2026年11月3日07:56（北京时间），Kxians（@xulijian1994）转述据称来自MIT的研究：GPT-6 Astra用Python读Qwen3.5-0.8B权重、结构与激活，定位第15和19层MLP，修改131072参数、称占0.016%，不用传统梯度训练。所报MATH-500为7.9%到48.1%、GSM8K为13.8%到67.1%，概括约六倍。解释是削弱重复循环相关异常方向而非注入数学知识；还称去掉输入输出层后，从三个小Transformer中间权重识别Python、英语和日语罗马字。

同日17:45:34的转述称研究者为MIT CSAIL博士生Rikiya Takehi及团队，新增IFEval21.0%到62.3%、达到token上限的循环回答93.0%到33.1%，Gemma3 270M只有6.8%到7.0%弱变化。该帖说某一层MLP，与较早两层说法不一致；另提权重识别游戏和扩散形状、小车／游戏控制0到100%，当时未给明细。

22:03:33的新候选将同一研究扩述为：从裸权重识别Breakout、Pong、Pac-Man和Freeway策略；改小车3.5%参数后成功率100%；手写Breakout网络权重，称得分是训练5亿步PPO的20倍；重复Qwen0.016%与7.9%到48.1%数字、称指令遵循三倍。它说全部执行日志和改后权重公开，与较早没有公开代码的转述冲突，未取得论文、日志、权重差分或匹配仓库，不擅自调和。
