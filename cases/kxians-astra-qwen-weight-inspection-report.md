# Qwen权重检查：Kxians转述Astra修改MLP缓解重复，并识别模型语言

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-11-03
阶段：待验证

2026年11月3日07:56（北京时间），Kxians（@xulijian1994）转述一项据称来自MIT的研究：GPT-6 Astra用Python读取Qwen3.5-0.8B权重、检查结构与激活，定位第15和19层MLP，修改131072参数，称占0.016%，不用传统梯度训练。帖子给出MATH-500从7.9%到48.1%、GSM8K从13.8%到67.1%的结果，概括为约六倍。所有数字、模型名和机构归属均按转述，不是本合集测量或算出的新结论。

作者解释主要削弱与重复循环有关的MLP异常输出方向，避免解题时不断重复，而非凭空新增数学知识。同一研究另有一项测试：去掉三个小Transformer的输入输出层，仅给中间层权重，Astra据称识别其学的是Python、英语和日语罗马字。两项测试作为同一权重理解研究的组成记录，不拆成虚构的独立项目。

同日17:45:34本窗口另一候选以“权重空间编程”转述同一组数字，称作者为MIT CSAIL博士生Rikiya Takehi及团队，并追加IFEval从21.0%到62.3%、达到token上限的循环回答从93.0%到33.1%；Gemma 3 270M从6.8%到7.0%的弱变化被用来支持除障而非注入知识的解释。新帖泛称某一层MLP，与较早第15／19两层说法并不完全一致，不自行调和。它还提到从权重识别游戏和扩散形状、小车与游戏控制从0到100%等实验，但没有任务明细和原始记录，不扩写成独立已验证项目。

较早补查确认Kxians署名，但公开仓库关键词检索没有取得可匹配原研究；新候选也没有原论文、评测材料或权重差分。其“没有开源代码／同行评审”的说法并非本合集对全网的核查结论，作者身份和论文状态仍未确认。新增数字是转述值而非此前缺失的原始重复率记录；无基准样本、随机种子与生成长度，不能认定普遍数学能力提升、真实理解全部参数或可推广到其他模型。未下载模型、改权重或运行评测，保留为详细但未核实的二手研究报告。
