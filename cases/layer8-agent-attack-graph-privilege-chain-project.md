# LAYER8：研究侦察与权限组合，让受限Agent共建攻击图并隔离验证

2026年11月16日07:19:57（北京时间），Michael Fischer（@Holden_Rye_）介绍LAYER8，称研究了攻击者的自动侦察、攻击图、权限串联、委托滥用，以及合法操作如何组合成入侵。本条记录的是从攻击行为研究反推防御分析系统的进行中设计，不是具名恶意二进制的已完成反编译。
