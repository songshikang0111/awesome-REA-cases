# Shopify Editions到个人站：Luca把HTML-in-Canvas研究整理成Claude Skill

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-11-06
阶段：待验证

2026年11月6日23:30:01（北京时间），Luca Vizzielli（@Viluca94）称逆向研究了Shopify新Editions站，把真实HTML逐帧绘入WebGL场景，使页面可弯曲、发光并三维移动，同时保留文字与可点击链接，随后用该结构重建自己的站点。帖子称视频前四秒为Shopify、其后是自己的站，补取确认视频附件存在，但未观看比较。

作者把难点定位为保留文本、链接、SEO、无障碍与不支持API的浏览器／手机回退，并称HTML-in-Canvas当时仍处Chrome origin trial，多数访客不支持。研究结果被整理为Claude Code Skill，含200行、零依赖starter、Chrome陷阱及上线QA，强调是结构而非固定外观模板。AI明确进入后续技能交付，但作者未说明用模型完成前期调查的具体步骤。
