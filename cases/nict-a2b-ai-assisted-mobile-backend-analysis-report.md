# 从APK反推后端：Tech Athletes转述NICT的A2B调查与AI分析成本

2026年11月24日21:26:40（北京时间），Tech Athletes（@IT_makesUsHappy）介绍App-to-Backend（A2B）攻击：从日本Google Play公开App入手，反编译并提取API主机、端点、参数与响应，再按每个后端定制攻击。作者称AI使这类分析更便宜，涉及SSRF、远程代码执行、SQL注入及IDOR／BOLA对象授权缺陷。目标是解释为什么客户端已加固仍不能替代服务端授权，而不是发布某款App的利用代码。

帖子将观察归于NICT的2026年10月13日报告，并转述JPCERT/CC于10月23日更新的案例类型：公开App中的端点／密钥、UI不可达接口、角色或账户操作、盲NoSQL注入及其他系统泄露的API密钥。建议盘点新旧API与测试环境、检查自8月以来日志、核查权限和注入、关闭闲置接口、限流并轮换暴露密钥。上述日期是作者引用的较早材料，不是本轮新抓取帖日期。
