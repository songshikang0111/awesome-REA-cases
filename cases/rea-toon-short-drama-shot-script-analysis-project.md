# rea-toon：从短剧逐镜研究人物、台词与结构，导出剧本和VIDEO.md的Agent项目

分类：算法与功能重建 · 其他 AI 逆向

阶段：相关项目

2026年11月14日23:13:14（北京时间），候选介绍JuneYaooo的新项目rea-toon：把本地短剧视频交给AI Agent，逐镜研究剧本、人物和制作安排，而不是逆向视频播放器或恢复拍摄工程文件。它建立在rea-video的切镜、人声／音乐分离之上，新增短剧叙事层，因此与既有rea-video记录分开收录。补读公开仓库固定提交d94acc1的英文README，其提交为同日14:31:41 UTC（北京时间22:31:41），属于早于候选的补充文档，不是新增候选。

文档描述先切镜和OCR字幕，再归并角色、确定逐句说话人、对照帧画面处理分歧，阅读场景、视线、戏剧节拍与信息差，最后由代码统计节奏、情绪账本和出场时间。输出是可打开的研读／剧本／分镜页面及VIDEO.md加video目录；剧本、分镜可导PDF，点击镜头可回放原片位置。跨集视图分析角色弧线、伏笔回收、集尾钩子和付费点。这些是项目说明，不证明它准确识别所有人物、说话人或致火原因；代码统计的是模型已标注的情绪，不能当客观情绪真值。

项目区分真人、AI真人、二维／三维动画、动态漫／梗漫与解说五类。需要Python 3.10以上、ffmpeg及视觉Agent或视觉API，支持Claude Code、Codex等；每集约30次视觉调用是文档估算，建议长剧先试5集，不是本合集测得的费用或速度。输入须为已在磁盘上的视频，链接不下载；合集需按集分文件，文档称可断点继续。当前页面和报告主要输出中文，英文演示是另译，不认定已支持完整英文产出。

README标明PolyForm Noncommercial 1.0.0，商用需作者书面许可；未另审LICENSE原文，也未取得视频权利，工具许可不授权原剧素材。本合集只读固定文档，未观看演示、安装依赖、运行CLI或核对分析输出。按具体AI辅助内容研究工具收录为related-project，不混同morluto的REA或软件反编译成果。
