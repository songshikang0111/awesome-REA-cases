# 百度网盘摇一摇广告：AI逆向的No Shake与磁力计解释尚未证实

分类：应用与客户端 · 其他 AI 逆向

2026年11月2日13:38:44（北京时间），Simbao（@lixinbao_X）转述澎湃新闻当日测试：在iOS 27.2将百度网盘加入限制动作数据名单后，开屏摇一摇广告仍可跳转。报道语境称该功能10月27日推出，限制陀螺仪和加速度计读取；本合集没有独立核实系统版本、权限实现或重跑记者操作。研究目标是解释为何限制运动数据后广告仍响应转动。

同帖称开发者用AI逆向猜测广告框架存在“No Shake”实现，系统不提供运动数据时使用另一套传感器。14:11:15另一候选明确转述为磁力计替代陀螺仪；14:54:03第三条又称定位功能中的磁力计。后两帖未附代码、调用链或权限实验，不能据重复传播确定磁力计确实被读取，亦不能证明No Shake名称等于某一已触发路径。AI模型、REA、APK／iOS二进制版本、函数和原始分析输出均未提供。

首帖同时保留知情人士的相反解释：并非特意绕开，而是新版适配仍在苹果审核中，预计近期更新。记者报告的广告跳转、开发者的逆向推断和这项解释是不同证据层级；不能把其中任一视为百度官方确认规避权限。应用内关闭摇一摇的客服建议也不是逆向路径验证。本合集补取首帖确认作者，未取得澎湃原文、开发者原始分析、设备或流量记录，未执行应用或更改权限；仅收录二手分析争议，不声称发现已证实的传感器漏洞。
