# AirPods 3头控鼠标：转述Claude Code研究RemoteHID与Linux MTU

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-11-05
阶段：待验证

2026年11月5日21:17:00（北京时间），一篇中文复盘转述开发者想把AirPods 3在Linux上用作头部控制鼠标，但所查五个开源项目均标不支持。称Claude Code先约300次蓝牙探测失败，人要求停止盲试，改查Wireshark插件、山寨耳机反编译材料和公开iOS框架伪代码，汇合六七个项目线索。

帖子把关键发现归于AirPods 3使用RemoteHID而非Pro系列传感器路径，以及Linux默认MTU 672与iOS 2582的差异；称改后有200Hz运动数据，随后生成驱动、控制台界面、37个自动化测试和公开协议文档。这些是转述数字和因果解释，不是本合集抓包、设备对照或测试结果，也不能据此保证改MTU适用于所有耳机与系统。“首次公开”及所有此前项目能力未核验。

未取得可固定的仓库、开发者署名、提交、完整协议文档或原始复盘链接正文；补充搜索看到同日更早相似转述，仅作线索、不替代本窗候选。保留为具体互通实验的未核验报告，不称破解加密或量产驱动。本合集未连接蓝牙、控制光标、执行驱动或测试；未提REA。
