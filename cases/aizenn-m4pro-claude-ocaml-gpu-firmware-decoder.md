# M4 Pro跑NixOS：Aizenn称与Claude写OCaml解码器恢复GPU固件布局，扬声器仍未处理

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-11-15
阶段：进行中

2026年11月15日21:09:36（北京时间），Aizenn（@brsy_10）称NixOS已在自己的M4 Pro上流畅运行。为适配其所称Apple在27.2更改的GPU固件接口，他与Claude用OCaml编写AArch64固件解码器，以恢复新布局。27.2是作者原样给出的版本标记，原帖没有更具体的固件版本或输入文件，本合集不替他补全。

补读同串同分钟回复：作者认为Helix比macOS上快，暂未遇到电池问题，同时明确归功于基于Aurora的许多补丁；这些是主观体验而非基准或独立完成整个Linux支持。21:09:37他又说扬声器仍需研究，有某种保护机制，自己担心损坏而不敢动。因此不能称所有硬件已支持，也不把GPU布局恢复等同完整驱动从零重建。

原帖附视频，但本合集未观看、取得解码器源码、核对固件结构或运行系统。未给工时、解析覆盖率或测试日志，REA未提及。以明确对象、语言与布局恢复目标的进行中AI辅助固件研究收录，系统运行与性能均保留作者归因。
