# Agent-PAL：让模型从DOS仙剑引擎研究走到全流程通关的基准报告

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-11-01
阶段：分析测试

2026年11月1日02:10:55（北京时间），Jianming Liu／冷月（@jianmliu）介绍自研Agent-PAL，称过去两周比较模型玩1995年DOS版《仙剑奇侠传》。其pure模式为L0零脚手架，不给攻略、寻路API，战斗脚本也由模型从零研究游戏引擎再编写，目标是11章全流程结局；这是把AI逆向作为游戏控制前置任务，而不只是对话答题。

作者称Gemini4 Argon、GPT-6.1-Sol、Claude Opus5.5三战三胜，平均2.6小时；DeepSeek V4 Pro／V4.1-Flash、GLM5.3、Kimi K3、MiniMax M3组花51.30小时、20192次工具、19.83亿Token，含一次人工提示仍未通关，并说DeepSeek在428回合耗尽月度额度。数字、组别汇总口径与开源声明均归于该帖；未取得可逐回合核验的代码、种子、费用账单或验收日志。

作者把差异解释为训练范式下的精神内耗，这不是由当前证据独立确立的原因，也不能推广为模型国别能力排名。未运行游戏、安装框架或复测通关；REA未在来源中出现，按作者基准报告保存。

候选快照0赞、43浏览；消耗与通关均为作者报告。
