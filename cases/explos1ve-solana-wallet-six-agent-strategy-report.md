# Solana钱包到六角色Agent：explos1ve的Claude策略重建与未核收益报告

2026年11月26日19:54:28（北京时间），explos1ve（@explosss1ve）称逆向研究Solana最赚钱的钱包，把团队逻辑变成Fable5.2上的六个Agent：radar只发现新交易对、rug shield筛开发者持仓与流动性风险、risk按实时余额定仓、sniper限制滑点、journal记交易理由、pnl记录收益。目标是从可见钱包行为反推自动交易分工，不是恢复Solana节点或智能合约源码。Fable5.2为作者原称，不另认证模型身份。

作者给Claude Code的提示要求六个角色，开发者持有不高于5%、前十持有不高于35%、流动性至少9000美元、LP锁定、无bundles，滑点上限2%，且先纸面跑一晚并展示日志。这些是拟定筛选规则，不是已验证防骗或成交保证；LP指流动性池，是否能准确发现bundles或持仓关联没有实现证据。
