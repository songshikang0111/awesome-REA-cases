# log接入Hermes：matt称本地处理会话，并以REA研究社交内部API

分类：应用与客户端 · REA
记录日期：2026-11-16
阶段：进行中

2026年11月13日01:56:09（北京时间），matt.（@matthewsoldit）介绍log，希望Agent利用用户既有会话发现机会，让用户把时间留给其他事情。他称已经把log集成为Nous Research Hermes Agent插件，且全部开源。这里记录的是作者项目公告，不是Hermes官方功能保证。

作者称log构建于@treg_ai、@subquadratic和@morluto的Reverse Engineer Anything之上，用来找到社交媒体或网站内部API，以便Agent控制操作。没有具体平台、端点、认证、授权范围、会话取得方式或支持动作，不能把‘任何网站’或‘每次会话’宣传理解为已经全面覆盖。

11月16日04:31:46的新候选补充，这是为Nous Research hackathon制作的插件，使用本地模型重排、分段并嵌入既有会话，作者称全部本地存储，让Agent更像用户本人。他明确说用REA反编译社交平台以接内部API，并称自己用Treg寻找相似的人、用log外联。这区分了会话个性化、潜客发现与平台研究三个环节，但不证明所有社交平台已支持、用户已授权每个动作或数据绝不出机。免费与开源仍为作者说法，未定位到仓库。

两次补取确认署名、正文与视频附件存在，未审视频执行、代码、API流量或本地存储。未安装插件、读取用户会话或发送外联；权限、安全边界与可用性未核。保持REA／in-progress，不把‘变成你’宣传升级成身份复制、官方支持或独立验证的账号控制。
