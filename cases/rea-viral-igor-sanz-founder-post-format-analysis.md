# REA Viral研究1661条独立创始人帖子：按作者自身基线拆格式而非承诺爆款

2026年11月24日18:44:33（北京时间），Igor Sanz（@mr_igor_sanz）介绍REA Viral是供AI Agent使用的开源skill，可给领域、账号或单帖，按作者自己的日常表现评分，输出格式、钩子、异常高低表现与制作配方。补读18:44:29和18:44:32父帖：他报告分析独立创始人领域1661条X帖子，短观点引用帖197条且仅0.93倍基线，列表格式在14位创作者中9位上有2.68倍，首行写自身收入的格式在5位创作者中有2.71倍。

这些是作者归类与样本相对表现，不是平台算法源码、随机实验或未来传播保证；2.68倍并非全体1661条的统一效果，收入数字也不是本工具带来的收入。

补充读取wpsoul/rea-viral的公开README：项目由指令与小型Python脚本组成，Agent用自己已有的公开材料读取工具，计算作者基线、查看有关视频，再交付HTML和ACCOUNT／POST／NICHE等报告与数据。文档要求分开MEASURED、SEEN和INFERRED，并列未读材料；缺历史关注数时不能把估计写成新增粉丝数，跨创作者格式至少三位才算领域模式。它不内置数据商，也不自行发帖；这些是文档约束，未经本合集运行验证。

仓库名称含REA不证明使用morluto/rea引擎，归other-ai。未固定提交、读取1661条原始样本、检查评分实现、重跑数字或发布内容。本合集仅核对作者串与可变文档，保留分析测试与观察性证据边界。
