# Danfoss冷柜控制器：Sonnet漏洞重建、Sekoia固件调查与维修idea

2026年11月3日05:30（北京时间），Hacked播客（@hackedpodcast）转述Claroty CTO、Team82的Amir Preminger：Sonnet读取Danfoss冷柜控制器研究，以约6美元重建已知漏洞，评估既有研究使复现变便宜的风险，不是首次发现零日。帖子谈便宜模型可能绕过护栏及欧洲冷柜攻击，没有建立AI参与真实攻击的因果链。07:11，ChrisR（@le_kryzz）问停更设备是否有逆向维修并建议AI重写；补取11月3日03:06父帖确定Danfoss，早于当轮04:00窗口，仅为背景。停更、受害商店和规模未独立核实，建议不是修补记录。

11月7日04:14:04与04:14:50，Frelzu（@Frelzu）转述Claroty用公开固件、已知漏洞和研究者监督，使Sonnet4.6约6美元、28分钟取得实验设备root；认证绕过最初做错，需研究者重新引导。后帖称有固件修复，但未核厂商公告或版本；又说法国攻击路径不明、无AI参与证据，美国军方未确认冷柜故障属攻击。保留这些来源当时的说法，不将实验连到现实事件。

11月10日02:22:49，Sekoia（@sekoia_io）新增自己的研究：把捕获请求与公开Danfoss固件交给未具名LLM，几分钟内确认无需认证即可改管理员账号名，这是密码重置的第一步。补取同串确认其称蜜罐在11月1日捕获尝试利用非公开bug，并称法国当局已将攻击归因IRGC的Shahid Kaveh／CyberAv3ngers；10月11日约2700控制器在线、约1700在法国也是其历史观测口径。原文与法国公告未核，不把新归因当本合集确认，也没有证据真实攻击者使用AI。该请求驱动的LLM分析与Claroty已知漏洞实验分开归属；不能把改名一步升级为完整密码重置、root或同一个CVE。

仍无控制器型号、CVE、原始输入输出、计费、复现或修复日志，完整播客未观看。Sonnet4.6、28分钟、root、几分钟和修复均为各来源报告，不能推成自主发现、通用成本或任意设备可靠利用。本合集未运行代码、接触设备或验证补丁，REA未说明。
