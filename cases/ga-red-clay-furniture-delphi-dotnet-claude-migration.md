# 家具厂Delphi转.NET：GA Red Clay称Claude Code重建业务系统，切换仍是计划

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-11-15
阶段：进行中

2026年11月15日02:01:05（北京时间），GA Red Clay（@Legal_Eagle_52）称用Claude Code把一家家具制造商的旧Delphi软件转为.NET。该企业通过零售店直接卖给消费者，系统覆盖零售与制造、会计、采购订单和库存。作者想从既有代码反推业务，再转成新实现，不重新访谈员工；这不是没有源码的二进制反编译报告。

作者称企业尝试迁移15年未成功，原系统近十年才完成，原开发费接近20万美元；现在约400美元AI费用、约一个月完成逆向，并说一个月后停用旧系统。这些时间、费用与历史均为个人自述。原开发包括业务访谈，AI费用不含等同范围的人工、迁移、基础设施或验收，不能算出可比成本降幅；一个月换系统仍是计划，不写成已经上线。
