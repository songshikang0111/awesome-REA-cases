# SM64桌面沙盘：Claude接Unity／PICO CLI的移植转述

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-11-01
阶段：待验证

2026年11月1日02:22:00（北京时间），Xiao Tan（@tvytlx）转述有人用一个周末把Super Mario64关卡做成PICO头显里的桌面沙盘，称原生3D、稳定90帧。帖子把Claude Code／Opus5.5的工作具体归为将既有反编译源码接Unity渲染器、转换N64几何数据、映射MR手柄和排查帧节奏；Unity CLI与PICO CLI支持终端内编译、部署和修改循环。

作者承认前置成果属于n64decomp，并称须持有原版提取素材。关于原ROM哈希一致、周末工时和90帧都是该帖说法，未取得构建、帧时间或代码。其PICO／Unity叙述与已收录Vision Pro及其他SM64空间demo不同，无法确认同一实现，因此不合并平台或借用旧案例验证。未确认原作者、运行头显或提取游戏素材；按第三方待验证移植报告收录。

候选快照3赞、269浏览；90帧和一个周末未经独立核验。
