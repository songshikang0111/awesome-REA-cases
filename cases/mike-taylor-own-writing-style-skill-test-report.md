# 按自己的文章调优write-like-mike：Mike Taylor的留出测试与双稿评审方法

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-11-23
阶段：待验证

2026年11月23日02:38:28（北京时间），阳明AI（@x_autonomy）新闻汇编第17项介绍Mike Taylor让AI模仿自己文风的技能调优。目标是从作者已有成品反推可用于新写作的风格行为，与他人的n8n实验分开。补查Every公开页面：Mike Taylor的《How I Finally Got AI to Write Like Me》标11月16日发布、11月22日更新；Grant Harvey的11月22日周报《Stop Telling AI How You Write. Show It.》介绍方法。这些窗口前材料只作本窗口候选的补充，不新增候选，也不把日期当实验日。

周报公开部分建议收集同一形式的12至25篇近期作品，留一部分做最终测试；让AI把各篇压成包含论点、事实、引文的普通brief，再从同一brief生成两篇草稿。AI评审拿原文比较哪篇更像作者，并交换双稿次序再评，以减轻顺序偏差；在实际写作模型上保留提高分数的Skill修改，最后用留出作品检查。它是按样本测试和优化写作行为，不是恢复唯一原始创作规则或反编译软件。

作者原文公开预览说明自己从2020年起尝试AI写作，过去让Claude按旧文写Skill仍不满意；现用/write-like-mike写文章，但仍逐次小改，本篇引言由自己重写，投稿后还有人类编辑。自述从有想法到成稿约一小时、此前一天，以及从每月一篇到每周一篇；不是无人工的一小时验收或受控提速倍数。文章标题提四种优化器和盲评，但登录后的完整方法、模型配置、Skill文件、原始样本与分数表未读，不补写名称和成绩。本合集只读公开预览和周报可见步骤，没有登录、绕过访问限制或运行写作流程，保留unverified，REA未提。
