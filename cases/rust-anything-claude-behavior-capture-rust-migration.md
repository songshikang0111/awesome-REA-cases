# rust-anything：先记录旧程序答案，再让Claude Code逐块重建Rust热点

2026年11月18日08:21:03（北京时间），codila（@0xCodila）介绍rust-anything，目标是在不破坏旧应用行为的前提下，把慢的部分迁到Rust。帖子列Python、JavaScript、TypeScript、Go、Ruby、Java、C为原项目语言，描述先运行旧代码，记录常规和边界输入的输出，作为答案基准，再让Claude Code分块重写，逐项对照后才继续。这是从可运行实现提取行为并重建的项目介绍，不是从闭源二进制恢复原始源码。

作者建议提供真实用户输入、只迁移热点、交付前比较新旧速度，也可逐块迁移全应用。但对照只覆盖已记录输入，不能证明全部路径或副作用等价。补读同作者08:31:36回复：文件写入称已检查，网络与数据库调用尚未支持；没有取得检查机制或结果。
