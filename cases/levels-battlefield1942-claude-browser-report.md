# Battlefield 1942浏览器版：从57000函数翻译到1.61同服的二手报告

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-11-05
阶段：待验证

2026年11月2日23:48（北京时间），dimash（@dimqshi）转述levels让Claude Code反编译Battlefield 1942的“C engine”，现在可在浏览器标签运行。目标是把2002年的游戏引擎带到网页；帖子把它称作abandonware，但该称呼不意味着版权终止或可分发原游戏。

11月3日09:05，澜知AI（@LanzhiAI）进一步转述levelsio用Claude Code／Opus 5.5处理57000个x86函数并转为WebAssembly，将DirectX 8渲染改成WebGL 2，且做出浏览器多人联机。帖子另称半年前尝试曾放弃；这不是已核实项目时间线，更不是现在只用一个Agent即可完成的工时测量。57000没有统计范围、代码清单或匹配分母，不能当成匹配率或恢复原C源码证明。

11月5日14:15:00的新候选细化为从demo反汇编x86、把函数译成约10万行C、以Emscripten生成Wasm，重写约300个Windows／Direct3D接口并以WebSocket接网络。其指令到READ32表达式的例子描述的是机器码语义翻译与兼容层，不等于恢复人工原始C源码。帖子还称后续升到2004年1.61版、浏览器玩家能与原客户端同服，支持iPhone／Android、最多64人；这些都是二手转述，所谓官方服务器也不作为EA认证。新帖承认竖屏会裁掉手臂和载具内部，作者自己仍不熟悉飞机操作；不能推断所有输入或渲染均正常。

早期两帖补取确认署名，但仍未取得levels原始说明、仓库、构建、演示URL、渲染／输入／网络测试或人工修正量。早期回复关于Ghidra和人工修复的问题没有答案；仍不能据此补全工具链。新增的是具体二手宣称，不是多人可用性、完整单人流程、跨浏览器兼容或无需原资源的独立验证。保持同一ID，与泛化Battlefield／Frostbite开放实现idea区分；未下载游戏、运行网页或接触原资产。

旧候选快照0赞、3浏览、0转发；11月3日新增候选0赞、20浏览、0转发。均为二手声称。
11月5日候选封存1赞、275浏览、0转发；10万行、约300接口、64人及一天／后两天的时间线均未独立核验。
