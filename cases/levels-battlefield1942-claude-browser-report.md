# Battlefield 1942浏览器版：新增57000函数与WebGL2的二手重建宣称

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-11-03
阶段：待验证

2026年11月2日23:48（北京时间），dimash（@dimqshi）转述levels让Claude Code反编译Battlefield 1942的“C engine”，现在可在浏览器标签运行。目标是把2002年的游戏引擎带到网页；帖子把它称作abandonware，但该称呼不意味着版权终止或可分发原游戏。

11月3日09:05，澜知AI（@LanzhiAI）进一步转述levelsio用Claude Code／Opus 5.5处理57000个x86函数并转为WebAssembly，将DirectX 8渲染改成WebGL 2，且做出浏览器多人联机。帖子另称半年前尝试曾放弃；这不是已核实项目时间线，更不是现在只用一个Agent即可完成的工时测量。57000没有统计范围、代码清单或匹配分母，不能当成匹配率或恢复原C源码证明。

两帖补取确认署名，但仍未取得levels原始说明、仓库、构建、演示URL、渲染／输入／网络测试或人工修正量。早期两条回复只问Claude是否读Ghidra输出、需要多少人工修复，没有答案；仍不能据此补全工具链。新增的是更具体的二手宣称，不是多人可用性、完整单人流程、跨浏览器兼容或无需原资源的独立验证。保持同一ID，与泛化Battlefield／Frostbite开放实现idea区分；未下载游戏、运行网页或接触原资产。
