# 蓝牙设备MCP桥接：QloveDudu复用Toy-Relay与sosexy协议，提供Agent辅助部署框架

2026年11月3日07:15（北京时间），@QloveDudu介绍面向成人蓝牙设备的开源集成框架：MCP可接官方App、Telegram Bot或自建前端，手机充当蓝牙中继，提供书写／语音到控制信号的映射、本地声音事件识别、反馈按钮、回放和三种面板主题。这里仅记录设备互通架构，不展开成人使用内容。作者称可把仓库上手提示交给Claude Code或Codex逐步部署，开源版为空白框架、免费非商用。

归因很明确：云端加手机中继的思路及啵啵贝协议来自Toy-Relay（@miao_tutu），原始协议逆向来自sosexy-ble-control。本条收录为AI工具可接入已有逆向协议的相关项目，而非声称作者或Claude重新恢复了BLE协议。作者称声音识别在手机本地、只上传事件，但语音合成接ElevenLabs；本地识别不等于整个系统离线或隐私已审计。
