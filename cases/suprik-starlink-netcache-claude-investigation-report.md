# Suprik的Starlink路由器：称Claude发现netcache模块与夜间外传

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-11-02
阶段：待验证

2026年11月2日02:34:57（北京时间），Suprik（@Supriik_）称在隐藏摄像头文章之后检查自有Starlink路由器，Claude发现非官方netcache模块，开机启动且管理页不显示；声称每晚2至4点向未知服务器发送约3.4GB，复制家中八台设备中六台的流量，涉及2316张照片、412份文档和18903条浏览记录。作者明确不指控Starlink监视，而称自己路由器遭人入侵。

作者称阻断目的服务器、停止模块并隔离、保存证据，再恢复出厂、更新固件、换Wi-Fi密码，并从干净设备更换所有密码。原帖与署名已补查，但无路由器型号、固件版本、模块文件／哈希、命令、捕获流量、对照镜像或事件报告；未确认数字来源与设备归属，更不能从转发流量推断能读取HTTPS加密照片或文档。

按具体设备的AI辅助异常调查自述保留，不写成确认感染、品牌漏洞或完整取证。方法、观察结果和处置效果均未独立验证；未提REA，也未扫描网络、获取样本或操作设备。

候选快照15赞、353浏览、0转发；3.4GB、六／八设备与文件数量均为作者未附日志的主张。
