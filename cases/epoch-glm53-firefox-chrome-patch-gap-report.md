# 浏览器补丁时差：Epoch的GLM5.3 Firefox/Chrome对照测试二手报告

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-10-31
阶段：待验证

2026年10月30日06:13:45（北京时间），Choblin（@choblin29）转述Epoch AI用开权重GLM5.3测试浏览器：Firefox投入超过10万美元，Chrome另约10万美元，同一harness未攻破Chrome，却据称在受控环境攻破9月17日至10月26日全部六个Firefox版本。所述方法是研究公开安全修复与用户收到修复之间的patch gap，不是证明发现所有未知漏洞。

作者称构造网页后只要访问就可窃取本地文件、无需点击，建立环境后每个新Firefox利用约1000美元，最快12小时自主开发，并称各提供商API都没有拒绝。这些数字、成功标准及自主程度均来自该转述，不能把最快时间当所有尝试的工时，也不能把无拒绝等同攻击正确或合法。REA没有提及。

2026年10月31日04:40:24，本轮另一条候选重述约1000美元、最快12小时、Chrome尝试10万美元仍未成功，并增加模型把补丁时差问题与此前未知的沙箱逃逸串联、网页访问后读取本地文件的说法。这是新的二手链式利用描述，不是本合集验证了零日发现，也没有足够信息判断其对应哪一Firefox版本、漏洞或全部成功尝试。

此前补查确认首帖署名与文字；截至本轮仍未取得Epoch原始实验报告、版本清单、日志或代码。没有执行利用、访问攻击页或测试浏览器。按未验证的比较研究报告收录，不认定现实Firefox用户被攻破，更不将Chrome一次限定测试失败写成永久安全。两款浏览器属于同一对照研究，不虚构为两套独立项目。

原候选快照39赞、2733浏览、7转发；新增候选3赞、869浏览、0转发。
超过10万美元、另约10万美元、六版本、每例约1000美元/最快12小时均是二手报告，未经本合集复测。
未知沙箱逃逸串联为新增候选主张，无漏洞标识或原始验证日志。
