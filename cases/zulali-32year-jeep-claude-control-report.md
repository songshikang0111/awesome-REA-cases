# 32年Jeep：SCI诊断、燃油修正公式与过检不等于合规的边界

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-11-14
阶段：待验证

2026年11月11日01:19:29（北京时间），Muhammad（@zulali）称Claude逆向了自己32年的Jeep，随后开始控制它。原帖还说视频用Fable 5.2编辑；不能把编辑模型标注当成车辆研究时的确切模型。早期补读同日03:31:50、03:32:09及03:37:37作者回复：这是周末实验，详情在视频，说明区有GitHub仓库，并打算上传部分会话。这些是11月11日背景，不是11月14日本窗口新候选；上传意愿不等于完整轨迹已公开。

11月11日10:18:15，Mia Sardinella（@MiaSardinella）质疑宣传，称已有文档与开源发挥作用，价值在诊断和修理；诊断命令激活发动机部件不等于控制转向、制动或自动驾驶。此前补查确认署名与文字，不是独立车辆审计。同日12:52:01，fly（@dailingfei3）称看过十分钟视频与仓库，识别目标为1994 Cherokee 4.0L、OBD1与SCI串口，转述3美元Arduino配Claude Code／Codex用于接线诊断、行驶日志与读取电脑程序；电阻压低信号导致初次失败，移除后凌晨1:38取得读数。约一周工作、刷写硬件早四个月缺元件、三根线加载小程序及写EEPROM均为fly描述，不是本合集已核读写能力。

fly还称ChryslerScanner公式把原始110解为+21.6%（最初约+22%），针对本机固件反汇编的换算应为-4.7%，依据包括计算例程与复位写128。本合集未读反汇编或核算公式；先核换算、不盲换零件是作者的建议。燃油泵被激活约十秒、AGENTS.md要求清故障码／重置修正／执行器测试逐次人工确认也是转述，书面规则不是强制隔离，读取不一概安全。

fly报告25 mph最初NOx702、限值539，每次检测约100美元，复测15与25 mph均13；同时说最后写入内容不清楚，过检不等于合规，并转述车主称过检未动法律有疑问的隐藏项。其援引加州车辆法27156与BAR软件／Cal ID／CVN规则，本合集未读法规、检测单或改写代码，既不判违法，也不以旧车不在某校验范围证明合法。

11月14日19:39:47的新候选点名xj-scanner，转述SCI约7800 baud与反相信号、约15美元材料，以及Codex编写EEPROM相关代码。补充读取MZULALI/xj-scanner固定9239683 README，提交日期2026-11-10 17:03:04 UTC，早于候选，仅作原项目背景。文档明确只在一辆1994 Jeep Cherokee XJ 4.0L、电脑56030117上构建测试；其它1991—95同族SBEC只是预期相近。文档列约15美元材料、3美元Nano、故障码／实时数据／行驶日志／内置测试；警告诊断插头有12V且不能凭线色接线，不在这里复述接线操作。

README把参数ID、换算、OBD1消息及故障码文本归功于László Dániel的ChryslerScanner，把燃油修正尺度归于AR1972/jeep_2.5L中的既有SBEC反汇编；这补强了人工与开源基础，不是AI重新独立发现每个协议字段。项目GPLv3。所读README未建立EEPROM改写、7800 baud、最终排放结果或合规的独立证据，仍按报道归因。此前未读仓库的限制现仅更新为已读固定README；视频、完整代码、固件、会话及检测报告仍未审。本合集未接车、下载目标、改写或执行指令，REA未提及，保持unverified。
