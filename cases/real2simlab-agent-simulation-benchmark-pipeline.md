# Real2SimLab：把视频反推仿真程序交回原基准评分器的统一评测平台

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-11-27
阶段：分析测试

2026年11月27日03:19:19（北京时间），Zefan Cai（@Zefan_Cai）介绍Real2SimLab，目标是将物理事件录制反推成仿真程序的不同方法接到多个基准，避免每个方法与每个基准分别集成及重写评分器导致口径漂移。帖子报告47个coding agent、5种非Agent方法和6个基准，并称训练／奖励管线先过滤与评测重叠的录制，再使用同一评分代码。

补读Real2SimHub/Real2SimLab的README，读取时仓库HEAD为1c36025f79f9f071fc419adb37166a8aefc3efdf（2026年11月26日08:46:51 UTC，窗口前）。文档将目标解释为从视频生成重现物理事件的程序，统一运行后冻结交付物、离线只读重跑，并在各基准自己的协议下评分。47个Agent来自Harbor 0.27支持范围，其中5种另有直接接入，不是47个都在本次帖子中完成全部评测。IRIS原始数据与项目自有synthetic套件使用Lab指标，不能把所有评分都说成第三方官方分数。

文档提出训练导出按相同文件／录制排除评测重叠，以及运行沙箱和网络限制；这些是项目说明，不是本合集安全审计、泄漏排除证明或全部物理参数唯一可辨识的结论。未读完整结果、实现或论文，也未安装依赖、运行Agent／仿真或复算分数。作为更广泛AI辅助行为／物理重建的评测工具项目收录，REA未提，规模数字不表示准确率。
