# iOS 4工程版8A218：二手报告称ChatGPT辅助QEMU启动九宫格多任务原型

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-11-14
阶段：待验证

2026年11月14日08:26:22（北京时间），沉浮（@chenfu336）转述开发者Steve Troughton-Smith近日在QEMU启动从iPhone 4工程机提取的iOS 4 build 8A218。QEMU是系统模拟器；此处目标是补齐旧系统运行条件，展示未公开原型，而不是AI从零写iOS。该帖称双击Home会出现类似Exposé的九宫格后台应用卡片，可点卡片切换，与后来左右滑动的界面不同。

据该转述，工程固件过去受驱动与硬件支持限制，开发者借ChatGPT编写和调试模拟器代码后使其运行。未取得开发者原帖、公开补丁、固件哈希、QEMU版本、设备模型、驱动清单或启动日志；无法确认哪些代码由AI完成、是否完整可交互，或何时首次运行。所谓十多年无人公开运行及几乎所有旧版iOS都能运行，均未经核实，不扩展为兼容性结论。

帖子把原型与最终多任务界面选择作历史对比，但这不能独立证明决策者动机或原型发布日期。REA未提及，本合集未下载工程固件、执行模拟器或复现界面；按具体但未核验的二手保存案例收录。
