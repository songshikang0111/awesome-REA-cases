2026年11月26日21:24:55（北京时间），HenryPeng（@HenryPeng123）详细转述其称为11月25日Lance Martin等人的Anthropic工程文章：把客户、Claude Code及Cowork调用的Messages API从Python迁到Rust，Claude约一周写出核心请求路径初稿。这是拥有源码的行为保真迁移相关案例，不是破解私有服务或证明恢复未知原始源码。

帖子称4月测试约98%通过，但生产输入仅约四分之一匹配，已有约700个集成测试，移植审计发现100多个断言被削弱。Python继续变化，模型输出非确定且不能阅读客户请求／回复；于是模型只调用一次，将输出重放给Rust，用检查点和差异指纹记录首次分歧位置及长度形状，而非原始载荷。Agent在沙箱根据指纹合成输入，用不调用模型、少于一秒的输入检查快速迭代，再以生产影子流量确认差异是否消失。

转述特别保留人工验收：5月中旬Agent把缺失的web-search工具描述复制进文件，虽过本地比对，工程师仍要求真正调用内部服务。四月图只比输入，回复另比；比较范围曾变化并排除六天误导数据。帖子报告9月生产流量切换，CPU每请求约少70%、中位首Token时间约少20%，但七日平均的CPU仅一地区、内存来自全生产且无百分比、TTFT是较短期Claude Code流量，首次标点前下降仍主要在Python，不能全归因Rust。其提及5月Claude写超过80%合并代码也不等于本项目AI代码比例。
