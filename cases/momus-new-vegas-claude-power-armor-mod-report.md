# New Vegas动力装甲：Momus称用Claude与社区反编译成果加入Fallout 4式玩法

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-11-18
阶段：待验证

2026年11月18日13:31:49（北京时间），Momus Digital（@MomusDigitalLLC）报告刚用Claude Opus 5.5，利用其社区发布的反编译成果，把Fallout 4风格的动力装甲加入Fallout: New Vegas。两者是不同的Fallout角色扮演游戏；本条目标是在旧游戏中改出较新作品风格的装甲体验，而非声称恢复了Fallout 4或New Vegas的全部原始源码。

这是基于已有逆向成果做AI辅助模组的第一人称自述。作者没有说明社区反编译项目名称、来源版本、Claude具体承担的代码工作、装甲机制覆盖、素材来源、安装方式或完成时长；不能推断包括完整进入/退出动画、动力核心、HUD或所有Fallout 4机制，也不把社区反编译本身归为Claude独立完成。
