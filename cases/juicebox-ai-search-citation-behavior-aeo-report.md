# Juicebox的AEO：反推AI搜索偏好的页面格式与品牌叙事

分类：算法与功能重建 · 未确认使用 REA
记录日期：2026-11-05
阶段：待验证

2026年11月5日03:26:24（北京时间），jam（@wespreadjam）以营销招揽帖介绍Juicebox的AEO（面向AI答案的搜索优化）。报告称研究AI反复信任的页面，发现清单、竞品比较与语义紧贴问题的内容更常被引用，遂制作20篇文章／指南／比较页，调整首页、schema、第三方引用及/ai-recruiting和/peoplegpt页面，并跟踪负面叙事与竞品优势。

其声称五篇以上博客进入Perplexity在40+招聘意图查询的高引用页面；两月AI搜索带来4500+注册，ChatGPT流量增336%、Perplexity增234%，20%+入站来自LLM。另称161次引用对YouTube119次、相关搜索出现85.4%，品牌情绪从2.35升到3.1／5，GPT-4o到GPT-5后两天调整策略。全部为帖子口径，不把这些数字外推至所有搜索、归因为单一内容改动或认定流量就是付费客户。

对象是AI检索／引用黑箱的行为观察，不是源码逆向；未说明AI模型参与分析或REA使用。没有原始查询、时间段、地区、模型设置、抽样、对照、引用日志、流量后台和注册归因数据，情绪指标定义也未知。不能由页面偏好认定恢复了ChatGPT或Perplexity内部排序算法，未独立审计业务结果，未运行搜索实验或接触客户数据。
