# 日聪蓄电池ECHONET Lite：Gemini对照HEX与遥控器，协议应答不等于执行

2026年11月11日17:00:28（北京时间），@Masato1864646的TechFeed汇总列出Gemini辅助ECHONET Lite解析第二篇文章。补充经Qiita公开API按标题找到matsukawa原文，发布于同日05:24:46、更新05:27:21北京时间，早于本轮窗口；原文回顾8月下旬至9月上旬工作，不把报道日期当实际实验日期。目标是自建家庭能源管理，读取日聪（Nichicon）蓄电池与家庭电力并安排充放电，避免另购约一万日元Wi-SUN模块与申请电表B-route。作者选择既有LAN与标准ECHONET Lite UDP接口，初期用浏览器Gemini生成Python、手动粘贴运行、回传错误；当前才逐步改用Antigravity。

作者先请求Panasonic AiSEG3分支回路数据，把双字节简单按无符号数解析得到异常8至9kW；与Gemini逐字节拆HEX后，发现高位含回路属性，不能整段当电流。因报文大、轮询迟缓，转查蓄电池Get属性表，并将疑似厂商扩展0xF5的12字节与遥控器实时数值对照：前四字节为有符号买卖电功率、中间保留、末四字节为光伏功率，再结合标准充放电读数推算家庭负载。字段解释与计算效果均为作者自测，未取得原始抓包复算。

排程研究先误用标准功率上限字段，设备回成功应答但遥控器时刻不变；随后在遥控器两组手工排程下取全属性HEX diff，定位21字节扩展0xF4并报告可反映时刻。已运行的放电又不会因改排程立刻停，作者另用运行模式控制。原文记录逆变器切换时异常值使SQLite溢出，增设长度与物理范围检查、跳过异常并保留前值；但其极大功率数值与32位解释不一致，不照抄为可靠测量。

低电量9%时，应用低于10%转待机的逻辑造成恢复后立即再待机、错过夜间充电；作者称通过修改状态机的充电时段例外改善。这里记录故障与作者处理，不推荐照搬保护例外或认为电池安全、厂商保护与电气合规已验证。文章还明确多脚本竞争UDP端口、局部粘贴修复会丢已有保护逻辑，因而计划用规格驱动Agent重构。未给精确设备型号、固件、模型版本、完整工程、长期收益或独立安全测试。REA未提及，本合集只读文章，未发送控制报文、接设备或运行代码。
