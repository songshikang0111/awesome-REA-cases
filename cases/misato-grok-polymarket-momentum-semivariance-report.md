# Polymarket五分钟BTC：Misato称用Grok Bot反推动量与半方差策略

2026年11月16日00:09:29（北京时间），Misato（@misat0x）称观察一个Polymarket公开账户后，与Grok Bot反推五分钟BTC市场的交易逻辑。作者称该账户94天赚148420美元、平均每笔约84美元、每小时重复30多次，但未给账户地址或明细，不能认证账户收益或策略身份。

其重建方案将BTC现价相对30秒前的百分比变化作为动量，再分别累加正收益与负收益的平方，以（上行方差－下行方差）／（上行方差＋下行方差）构成Skew；只在两者同向时触发。这里的Skew是作者命名的半方差不对称指标，不是已恢复原机器人源码，也没有证据证明它能领先订单簿形成可交易优势。Grok Bot未被认定为特定官方产品或模型版本，REA未提及。

作者报告七天纸面交易扫描1420个五分钟窗口，84笔触发、68胜16负，自称80.9%胜率、固定100美元规模模拟盈利3840美元、最差日亏42.10美元；并称加入过滤前费用造成亏损，过滤后减少94%的坏入场。没有时间戳、成交模拟、费用／滑点口径、原始日志或代码，数字均为自述而非本合集核算或实盘收益。补取原帖只确认署名与文字；未观看视频、运行策略、连接钱包或下单，不提供收益保证。
